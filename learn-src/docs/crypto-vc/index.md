# 加密创投教程

从零开始系统理解加密世界的创业与投资逻辑——5 章 29 课，全部基于 2025-2026 年最新行业数据。

### 第一章：公链基础篇

理解比特币、以太坊、Solana 三大主流公链的设计原理，掌握"不可能三角"，并完成第一个钱包实操。

### 第二章：实务操作篇

从交易所开户、钱包基础、安全防骗到投资心态与风险控制，构建你进入加密世界的"安全装备"。

[👉 进入第二章概述](/crypto-vc/start/chapter2-overview/)

### 第三章：金融篇

读懂稳定币市场格局、生息稳定币、机构 ETF 通道，再到 DeFi 基础、Uniswap 与 HyperLiquid 实战。

[👉 进入第三章概述](/crypto-vc/advanced/chapter3-overview/)

### 第四章：文化篇

NFT、链游 GameFi、Memecoin 与注意力经济、Pump.fun 发射台、KOL 评估、RWA 代币化——理解加密文化层的话语权。

[👉 进入第四章概述](/crypto-vc/advanced/chapter4-overview/)

### 第五章：创新篇
