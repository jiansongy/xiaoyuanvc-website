# 加密创投教程

从零开始理解加密世界的产品、技术、金融机制与创业机会。新版教程以 2026 年课程底稿为基础，整理成五个可以独立阅读、也可以顺序学习的完整章节。

::: warning 先说风险
本教程只用于教育与研究，不构成投资、法律或税务建议。加密资产价格波动大，平台、智能合约、私钥和监管均可能带来损失；开始任何真实操作前，请确认所在地法律与平台规则，并只使用能够承受全部损失的资金。
:::

## 推荐学习方式

1. 先建立整体地图，再深入术语；不必在第一次阅读时记住所有缩写。
2. 使用 **RSA：Read、Search、Ask**。先读原始资料，再搜索交叉验证，最后向可靠的人或 AI 提问。
3. 只在测试网或模拟环境练习，确认地址、网络、授权和交易含义后，再考虑真实资产。
4. 对所有收益承诺、陌生私信、空投链接和签名请求保持“零信任、持续验证”。
5. 研究产品时，把注意力放在用户问题、机制、收入、风险和竞争格局，而不只看代币价格。
