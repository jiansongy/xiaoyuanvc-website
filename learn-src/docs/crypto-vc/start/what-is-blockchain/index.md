## 核心思路

### 区块链和比特币的关系

先纠正一个常见误解：区块链不等于比特币。

比特币是一种**应用**，区块链是它的**底层技术**。就像微信是一个应用，互联网是它的底层技术。先有比特币，后有"区块链"这个概念被提炼出来。

后来人们发现，区块链技术不只能用来做数字货币，还能做智能合约、去中心化应用、数字身份等很多事情。这就是以太坊等平台出现的原因，后面课程会讲到。

### 区块链是什么

::: info 一句话定义
**区块链**是一种去中心化、公开透明的分布式账本技术。简单说，就是一个"全球共享的记账本"，所有人都能看到，没人能偷偷改。
:::

传统的记账方式是**中心化**的：银行记录你的余额，支付宝记录你的交易。你信任这些机构不会出错、不会跑路。

区块链的记账方式是**去中心化**的：不是一家机构说了算，而是全球成千上万台计算机一起记账。每个人都有一份完整的账本副本，任何人都可以查看和验证。

#### 村庄记账的类比

想象一个 100 人的村庄，以前靠村长一个人记账。村长要是偷偷改数字，或者账本丢了，大家就麻烦了。

现在换一种方式：每发生一笔交易，就大声喊出来，全村 100 个人同时记到自己的本子上。想改账？你得同时说服超过一半的人跟你一起改，几乎不可能。

这就是区块链的基本思路：**用集体记账代替个人记账，用数学规则代替人际信任**。

### 区块链的四大特性

| 特性 | 含义 | 现实中的对比 |
|------|------|-------------|
| **无需许可** | 任何人都能加入网络，不需要审批 | 银行开户需要审批，区块链不需要 |
| **无需信任** | 不依赖任何中间人，规则由代码执行 | 不需要信任银行、支付宝等机构 |
| **公开透明** | 所有交易记录公开可查 | 银行只让你看自己的账户 |
| **无法篡改** | 写入后不可修改或删除 | 银行可以更正记录，区块链不行 |

::: tip 注意
"无法篡改"不是说绝对不可能，而是篡改的成本极高（需要控制全网大部分算力），在实际操作中几乎不可行。
:::

### "区块"+"链"是怎么回事

区块链这个名字已经告诉你了它的结构：**区块** + **链**。

**区块**（Block）：一页账本。每隔一段时间（比特币约 10 分钟），网络把这段时间内的交易记录打包成一个区块。

**链**（Chain）：把所有区块按时间顺序串起来。每个新区块都包含前一个区块的"指纹"（哈希值），形成一条链。如果有人改了中间某个区块，后面所有区块的"指纹"都对不上，篡改立刻被发现。

```
区块链结构示意

┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ 区块 #0  │────→│ 区块 #1  │────→│ 区块 #2  │────→│ 区块 #3  │
│ (创世块) │     │          │     │          │     │ (最新)   │
│          │     │ 前块哈希 │     │ 前块哈希 │     │ 前块哈希 │
│ 交易记录 │     │ 交易记录 │     │ 交易记录 │     │ 交易记录 │
│ 时间戳   │     │ 时间戳   │     │ 时间戳   │     │ 时间戳   │
└──────────┘     └──────────┘     └──────────┘     └──────────┘

每个区块通过"前块哈希"指向前一个区块，形成不可断裂的链条
```

::: info 什么是哈希值？
**哈希值**就像一个"数字指纹"。你输入任何数据，哈希函数会输出一串固定长度的字符（比如 `a1b2c3d4...`）。输入哪怕改一个字，输出会完全不同。这个特性让篡改变得极易被发现。
:::

### 互联网传递信息，区块链传递价值

互联网让你可以瞬间把一张照片发给全世界，但有一个问题：信息可以复制，价值不能。

你发一封邮件给朋友，你们俩都有这封邮件的副本。但你转 100 块钱给朋友，你必须少 100，他多 100，不能"复制"。

在区块链出现之前，"在互联网上转移价值"必须依赖银行等中间人来确保"你减少了，他增加了"。区块链解决了这个问题：通过全网共识机制，保证每一笔转账"一减一加"准确无误，不需要中间人。

这就是为什么有人说：**互联网是信息的高速公路，区块链是价值的高速公路**。

### 区块链的演进

区块链技术经历了几代发展：

| 阶段 | 代表 | 能力 | 时间 |
|------|------|------|------|
| **区块链 1.0** | 比特币 | 数字货币，点对点转账 | 2009 年 |
| **区块链 2.0** | 以太坊 | 智能合约，去中心化应用 | 2015 年 |
| **区块链 3.0** | Solana 等 | 高性能，低费用，大规模应用 | 2020 年后 |

从"只能转账"到"能跑程序"再到"能大规模使用"，区块链的能力边界一直在扩展。接下来几课我们会逐一学习以太坊和 Solana。

## 跟我做：在线体验区块链

### 第 1 步：打开在线演示

**为什么**
亲手操作比看十遍文字都管用。这个演示网站让你实际感受区块和链是怎么工作的。

打开浏览器，访问：[andersbrownworth.com/blockchain/](https://andersbrownworth.com/blockchain/)

**你应该看到**：一个简洁的页面，上面有几个输入框和按钮

### 第 2 步：体验哈希

**为什么**
理解"输入变一点，输出完全变"的哈希特性。

1. 点击 **Hash** 标签页
2. 在输入框中输入任何文字（比如"你好"）
3. 观察下方生成的哈希值
4. 修改一个字（比如改成"你们好"），看哈希值的变化

**你应该看到**：哪怕只改了一个字，哈希值完全不同

### 第 3 步：体验区块

**为什么**
理解一个区块包含什么信息。

1. 点击 **Block** 标签页
2. 你会看到一个区块，包含：Block（编号）、Nonce（随机数）、Data（数据）、Hash（哈希值）
3. 在 Data 中输入一些内容
4. 点击 **Mine** 按钮

**你应该看到**：程序自动尝试不同的 Nonce，直到找到一个让哈希值满足条件（前面有几个 0）的值。区块变成绿色，表示"挖矿成功"。

### 第 4 步：体验链

**为什么**
理解区块之间是如何通过哈希值串联的。

1. 点击 **Blockchain** 标签页
2. 你会看到多个区块串成一条链
3. 修改第一个区块的数据
4. 观察后面所有区块发生了什么

**你应该看到**：修改一个区块后，它和后面所有区块都变成红色（无效）。这就是"无法篡改"的原理：改一个，后面全作废。

## 踩坑提醒

::: warning 误区一："区块链就是比特币"
区块链是技术，比特币是应用。以太坊、Solana 也是区块链，但不是比特币。
:::

::: warning 误区二："区块链能解决所有问题"
区块链适合需要"去信任"和"不可篡改"的场景，但不是万能的。存照片用云盘更好，不需要上链。
:::

::: warning 误区三："去中心化意味着没人管"
去中心化是指没有单点控制，但区块链有自己的规则（代码）和治理机制。不是无序的。
:::

## 本课小结

区块链是一种去中心化的分布式账本技术，核心解决的是"不需要中间人就能安全地传递价值"。

几个核心要点：
- **和比特币的关系**：区块链是底层技术，比特币是第一个应用
- **四大特性**：无需许可、无需信任、公开透明、无法篡改
- **数据结构**：区块通过哈希值串联成链，改一个后面全废
- **价值传递**：互联网传信息，区块链传价值
- **技术演进**：从比特币(1.0)到以太坊(2.0)到 Solana(3.0)
