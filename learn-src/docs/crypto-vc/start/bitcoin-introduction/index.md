## 核心思路

### 比特币是什么

::: info 一句话定义
**比特币**（Bitcoin，简称 BTC）是全球第一个去中心化的加密货币，由化名"中本聪"的人在 2008 年发明。它不由任何政府或公司控制，总量固定 2100 万枚，通过密码学和计算机网络实现"在互联网上安全地传递价值"。
:::

你可以把比特币理解成一种"数字世界的黄金"：稀缺、不可增发、全球通用、任何人都可以持有。

### 比特币为什么诞生

故事要从 2008 年说起。

那一年，美国爆发了严重的金融危机。雷曼兄弟倒闭，多家大银行濒临破产，全球股市暴跌。政府的应对方案是大量印钞救市，但这导致了另一个问题：货币贬值。

普通人的钱存在银行里，银行倒了可能拿不回来；政府印钱，手里的钱越来越不值钱。这让很多人开始思考：有没有一种钱，不依赖银行，不受政府控制，不会被随意增发？

2008 年 10 月 31 日，一个叫"中本聪"（Satoshi Nakamoto）的人在密码学邮件列表发了一篇 9 页的白皮书，标题是《比特币：一种点对点的电子现金系统》。核心观点只有一个：

> 不需要信任第三方，就能在互联网上完成价值转移。

2009 年 1 月 3 日，中本聪挖出了比特币的第一个区块，叫**创世区块**（Genesis Block）。他在区块里嵌入了一条消息：

> "The Times 03/Jan/2009 Chancellor on brink of second bailout for banks"

这是当天《泰晤士报》的头条：财政大臣正准备第二次救助银行。中本聪用这条消息表明了态度：比特币就是为了应对传统金融体系的问题而生。

::: tip 中本聪至今是谁？
没人知道。中本聪可能是一个人，也可能是一个团队。他在 2010 年后逐渐淡出社区，把比特币交给了全球开发者维护。他的钱包里大约有 110 万枚 BTC，从未动过。
:::

### 比特币怎么运转

比特币不靠银行，那谁来记账？答案是：全球的矿工。

#### PoW 工作量证明

::: info 什么是 PoW？
**PoW**（Proof of Work，工作量证明）是比特币的共识机制。简单说就是：谁的计算机算得快，谁就有权记录这一批交易，并获得比特币作为奖励。这个过程叫"挖矿"。
:::

挖矿的流程大致是这样：

```
┌─────────────────────────────────────────────────────────────┐
│  第1步           第2步           第3步           第4步       │
│  收集交易    →   打包区块    →   计算哈希    →   广播验证   │
│                                                             │
│  矿工收集        把交易打包      不断尝试        其他节点    │
│  待确认交易      成一个区块      不同数字        验证结果    │
│                                  直到找到        确认有效    │
│                                  符合条件                    │
│                                  的答案                      │
└─────────────────────────────────────────────────────────────┘
```

矿工需要找到一个数字（叫 nonce），让区块的哈希值满足特定条件。这个计算很费时间，但验证结果很容易。就像做数独：解题花时间，但检查答案一眼就行。

PoW 机制保证了三件事：

- **公平**：谁投入算力多，谁更可能获得奖励
- **安全**：要篡改记录，需要控制全网 51% 以上算力，成本极高
- **去中心化**：任何人都可以参与，不需要批准

#### 2100 万枚的总量限制

比特币最独特的设计之一：总量永远只有 2100 万枚，一枚都不会多。

怎么做到的？每隔约 4 年，矿工的挖矿奖励会减半：

| 时间段     | 每个区块奖励 | 说明                         |
| ---------- | ------------ | ---------------------------- |
| 2009-2012  | 50 BTC       | 初始阶段                     |
| 2012-2016  | 25 BTC       | 第一次减半                   |
| 2016-2020  | 12.5 BTC     | 第二次减半                   |
| 2020-2024  | 6.25 BTC     | 第三次减半                   |
| 2024-2028  | 3.125 BTC    | 当前阶段                     |
| ...        | 持续减半     | 最终趋近于0                  |
| 约 2140 年 | 0            | 全部挖完，矿工只靠交易手续费 |

目前已经挖出约 1970 万枚（约 94%），剩下的 130 万枚需要 100 多年才能挖完。

::: tip 比特币不是"一个一个"买的
1 枚 BTC 可以分割到小数点后 8 位，最小单位叫"聪"（Satoshi，简称 sat）。1 BTC = 1 亿聪。你可以只买 0.001 个 BTC，不需要买整个。
:::

### 为什么叫"数字黄金"

比特币和黄金有很多相似之处：

| 特性         | 黄金             | 比特币                 |
| ------------ | ---------------- | ---------------------- |
| **稀缺性**   | 地球储量有限     | 总量 2100 万枚         |
| **便携性**   | 沉重，运输成本高 | 一串代码，全球秒转     |
| **可验证**   | 需要专业设备鉴定 | 任何人可以在链上验证   |
| **可分割**   | 分割困难         | 可分到小数后 8 位      |
| **存储成本** | 需要保险柜       | 存在钱包里，几乎零成本 |
| **供应增速** | 每年约 2% 新开采 | 约每 4 年减半          |
| **抗通胀**   | 数千年共识       | 代码保证不增发         |

但比特币在一些方面超越了黄金：跨境转移更快、存储更便宜、验证更容易。

### 2025 年的比特币

来看看比特币目前的市场地位：

| 指标              | 数据      | 说明                     |
| ----------------- | --------- | ------------------------ |
| 历史最高价（ATH） | $124,774  | 2025 年 10 月            |
| 年末价格          | $87,520   | 年跌幅 -6.4%             |
| 波动率            | 41.6%     | 仍然是高波动资产         |
| 市值占比          | 57.4%     | 在所有加密货币中的份额   |
| 加密总市值        | $3.0 万亿 | 相当于一个中等国家的 GDP |

::: warning 别被"只跌了 6.4%"迷惑
BTC 年内从最高 $124,774 跌到 $87,520，中间经历了多次剧烈波动。10 月曾触及历史新高后快速回落。加密市场的波动性远超股市。
:::

**机构在大举入场**：

- **ETF**：贝莱德的 IBIT 基金，上市仅 341 天 AUM 就达到 $700 亿，被称为"ETF 历史上最伟大的发行"。所有比特币 ETF 合计持有约 132 万枚 BTC，总规模超过 $1200 亿。
- **企业**：Strategy（原 MicroStrategy）持有 65 万枚 BTC，价值约 $595 亿。全球约 200 家上市公司持有比特币。
- **政府**：美国建立了"战略比特币储备"（SBR），白宫称比特币为"战略货币商品"。

### 两个真实故事

#### 故事一：比特币披萨节

2010 年 5 月 22 日，程序员 Laszlo Hanyecz 在论坛发帖：

> "我出 10,000 个比特币，换两个披萨"

有人接了单，用两个 Papa John's 披萨换走了这 10,000 枚 BTC。按现在价格，这两个披萨值大约 **80 亿人民币**。

每年 5 月 22 日被定为"比特币披萨节"，纪念比特币第一次购买实物商品。

::: tip 别只看到"亏了"
这个故事常被用来嘲笑"卖早了"，但那时候 1 BTC 不到 1 分钱，根本没人把它当钱。Laszlo 其实推动了比特币的第一次真实使用，他对比特币的发展功不可没。
:::

#### 故事二：山东县城的比特币持有者

一个山东小县城的朋友，2014 年卖了一套房子，买了 15,000 个比特币。现在还持有上万枚，市值近百亿人民币。

这个案例说明什么？

- **普通人也有机会**：非名校、非大厂，小县城也能抓住机遇
- **HODL 的力量**：长期持有（Hold On for Dear Life）是比特币社区的核心信仰
- **但这是极少数**：能拿住 10 年不卖的人凤毛麟角

::: danger 幸存者偏差
你听到的都是赚钱的故事，但大量在中途亏损卖出的人不会站出来讲。不要被个案冲昏头脑，理性看待。
:::

## 跟我做：用区块链浏览器看比特币

### 第 1 步：打开区块链浏览器

**为什么**
区块链浏览器是查看比特币链上数据的公开工具，你可以亲眼看到每一笔交易和每一个区块。

打开浏览器，访问：[blockchain.com/explorer](https://www.blockchain.com/explorer)

**你应该看到**：一个显示最新区块和交易的实时页面

### 第 2 步：查看创世区块

**为什么**
创世区块是比特币的"第一块砖"，里面有中本聪留的历史性消息。

在搜索框输入区块高度 `0`，或直接访问：
https://www.blockchain.com/explorer/blocks/btc/0

**你应该看到**：

- 区块高度：0
- 时间：2009 年 1 月 3 日
- 奖励：50 BTC
- 交易数：1

### 第 3 步：找到泰晤士报消息

**为什么**
亲眼看到这条刻在区块链上的消息，感受一下"不可篡改"的意义。

在创世区块页面找到 Coinbase 字段，你会看到：

```
The Times 03/Jan/2009 Chancellor on brink of second bailout for banks
```

这条消息从 2009 年至今一直在链上，任何人无法修改或删除。

**你应该看到**：一段十六进制编码的数据，解码后就是这句话

### 第 4 步：查看最新区块

**为什么**
对比创世区块和最新区块，感受比特币网络 16 年来的持续运行。

回到首页，点击最新区块，观察：

- 当前区块高度（已超过 87 万）
- 每个区块的交易数量（通常数千笔）
- 当前挖矿奖励（3.125 BTC）

**你应该看到**：比特币网络大约每 10 分钟产出一个新区块，全年无休

### 第 5 步：看一笔真实交易

**为什么**
理解比特币交易的结构。

点击任意一笔交易，观察：

- 输入（从哪个地址发出）
- 输出（发到哪个地址）
- 交易金额
- 手续费
- 确认次数

**你应该看到**：每笔交易都有清楚的来源和去向，完全公开透明

## 踩坑提醒

::: warning 误区一："比特币就是骗局"
比特币技术本身不是骗局，但有人利用比特币的概念行骗。记住 DYOR（Do Your Own Research），自己研究、自己判断。
:::

::: warning 误区二："现在入场太晚了"
2015 年有人说太晚，2019 年有人说太晚，2022 年还有人说太晚。比特币的机构采用才刚开始（ETF、SBR），但这不代表一定会涨，做好风险管理最重要。
:::

::: warning 误区三："比特币会被政府禁止"
2025 年美国已经建立了战略比特币储备，正式承认 BTC 为"战略货币商品"。主要经济体的态度正在从观望转向拥抱。
:::

::: danger 投资风险

- 比特币价格波动极大，短期内可能下跌 50% 以上
- 私钥丢了 = 资产永远没了
- 只投入亏得起的钱
- 不要听信任何"稳赚"的说法
  :::

## 本课小结

比特币诞生于 2008 年金融危机之后，由中本聪提出，是全球第一个去中心化加密货币。

几个核心要点：

- **PoW 共识**：矿工通过算力竞争记账，维护网络安全
- **2100 万枚**：总量固定，约每 4 年减半，2140 年全部挖完
- **数字黄金**：稀缺、可分割、全球流通、抗通胀
- **机构入场**：ETF 持有 132 万枚 BTC，美国建立战略比特币储备
- **高波动**：2025 年 ATH $124,774，年末 $87,520，适合长期持有
