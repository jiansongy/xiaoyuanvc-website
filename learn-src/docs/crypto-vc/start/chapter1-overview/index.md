# 第一章：公链与区块链基础

公链是加密行业的地基。本章从比特币开始，解释区块链为什么能在没有中心机构的情况下维护一套公共账本，再用以太坊说明公链如何从“记账工具”发展成“可编程平台”。

## 学习目标

- 说清公链、区块链、共识、矿工和代币之间的关系
- 理解比特币为何被称为“数字黄金”
- 区分 PoW 与 PoS，也区分比特币和以太坊的设计目标
- 能在测试网完成一次安全的链上观察
- 建立持续自学加密行业的方法

## 为什么加密行业难入门

加密行业同时涉及计算机科学、网络、金融、全球政策和群体共识，而且变化很快。有效的入门方法不是追逐每天的新闻，而是先建立一张产品地图：

| 层级 | 解决的问题 | 代表概念 |
| --- | --- | --- |
| 公链 | 谁来维护公共账本 | Bitcoin、Ethereum、PoW、PoS |
| 资产与身份 | 谁真正控制资产 | 地址、私钥、钱包、签名 |
| 应用 | 公共账本上能做什么 | 稳定币、DeFi、NFT、预测市场 |
| 研究 | 如何形成判断 | 原始资料、链上数据、交叉验证 |

贯穿全教程的原则是：**以产品视角切入，理解机制与风险，再判断机会。**

## 什么是公链

公链（Public Blockchain）是一种开放的区块链网络：任何人都可以读取账本、发送合法交易，并按照公开规则参与网络。它通常具备四个核心特征：

- **无需许可**：不需要某家公司批准才能使用。
- **无需信任**：规则和验证替代了对单一机构的信任。
- **公开透明**：交易和区块可以被独立查询。
- **难以篡改**：修改历史记录需要付出极高成本并获得网络共识。

你可以在 [Blockchain.com Explorer](https://www.blockchain.com/explorer/assets/btc) 观察比特币区块持续产生，也可以用 [Anders Brownworth 的在线演示](https://andersbrownworth.com/blockchain/) 理解哈希变化如何影响整条链。

## 比特币：具有绝对稀缺性的数字资产

比特币是第一个成功运行的去中心化加密货币。它以工作量证明（PoW）选择记账者，通过公开账本记录价值转移，并把总量上限写入协议规则，因此常被称为“数字黄金”。

### 核心机制

| 机制 | 含义 |
| --- | --- |
| PoW | 矿工投入计算和能源竞争出块权 |
| 区块奖励 | 网络向成功记账者发行新币并支付手续费 |
| 总量上限 | 协议规定最多产生 2,100 万枚 BTC |
| 自托管 | 掌握私钥的人才真正控制对应资产 |
| 公开验证 | 任何人都能运行节点并核对账本规则 |

### 关键历史

| 时间 | 事件 |
| --- | --- |
| 2008 年 | bitcoin.org 注册，中本聪发布白皮书 |
| 2009 年 | 比特币网络上线，创世区块产生 |
| 2010 年 | “比特币披萨”成为早期真实交易案例 |
| 2011 年 | 早期交易市场发展，也暴露交易平台安全风险 |
| 此后 | 减半、机构持有和监管变化持续影响生态 |

重要人物和延伸资料包括匿名创始人中本聪、维护 [Bitcoin Information](https://www.lopp.net/bitcoin-information.html) 资料库的 Jameson Lopp，以及推动企业持币策略的 Michael Saylor。

### 仍需观察的问题

- 随着区块奖励降低，手续费能否长期支撑网络安全预算？
- 量子计算的发展会在何时要求地址和签名方案升级？
- 价值储存叙事、支付用途和监管环境会如何变化？

这些问题都没有简单答案，研究时应区分协议事实、市场数据和个人预测。

## 区块链如何创造“价值网络”

传统互联网擅长复制信息，但价值不能被无限复制。银行和支付公司通过中心化账本解决“同一笔钱不能花两次”的问题；区块链则让分散的参与者按照同一套规则维护账本。

一次典型的价值传递可以概括为：

| 步骤 | 网络发生什么 |
| --- | --- |
| 1. 发起 | 用户创建交易并用私钥签名 |
| 2. 广播 | 交易被发送给网络节点 |
| 3. 验证 | 节点检查签名、余额与规则 |
| 4. 共识 | PoW 或 PoS 按规则选择出块者 |
| 5. 记账 | 合法交易被写入新区块并由全网继续确认 |
| 6. 激励 | 出块和验证参与者获得协议奖励或手续费 |

密码学让身份和数据关系可验证，共识机制让分散节点对账本状态达成一致。因此可以把密码学理解为“骨架”，把共识理解为“灵魂”。

## 比特币与以太坊

| 维度 | 比特币 | 以太坊 |
| --- | --- | --- |
| 核心定位 | 稀缺数字资产与价值账本 | 可运行智能合约的公共计算平台 |
| 常用比喻 | 计算器、数字黄金 | 全球计算机、应用操作系统 |
| 共识 | PoW | 2022 年后使用 PoS |
| 主要状态 | 谁拥有多少 BTC | 账户、合约代码与应用状态 |
| 典型用途 | 储值、转账 | 稳定币、DeFi、NFT 和其他 DApp |

以太坊支持图灵完备的智能合约。程序的执行结果会被写回公共账本，让互不信任的参与者可以验证同一个结果。第三章会进一步解释账户、Gas、交易生命周期和二层网络。

## 用测试网观察一笔交易

::: tip 只用测试网
下面的练习不需要真实资金。安装钱包前核对官网，绝不向任何人透露助记词或私钥。
:::

1. 从 [MetaMask 官网](https://metamask.io/download/) 安装钱包。
2. 切换到 Ethereum Sepolia 测试网。
3. 通过可信测试网水龙头领取少量测试 ETH，例如 [Google Cloud Web3 Faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia)。
4. 向自己的另一个测试地址发送一小笔测试 ETH。
5. 在 [Sepolia Etherscan](https://sepolia.etherscan.io/) 查询交易哈希，观察状态、区块、Gas 和确认数。

测试币没有真实价值。这个过程的重点是看懂“签名—广播—打包—确认”，而不是交易收益。

## 工具与自学方法

- [CoinGecko](https://www.coingecko.com/)：查看市值、分类、交易量和观察列表。
- [Crypto Tree Map](https://cryptotreemap.com/)：用面积和颜色观察市场结构。
- [Bitcoin Explorer](https://www.blockchain.com/explorer/assets/btc)：查看比特币区块与交易。
- [Etherscan](https://etherscan.io/)：查看以太坊账户、合约和交易。

遇到陌生术语时使用 **RSA**：

1. **Read**：先读协议官网、白皮书或文档。
2. **Search**：搜索不同立场的解释和反例。
3. **Ask**：让 AI 用不同难度解释，再向可信社区求证。

如果想从内容研究进入行业，可以选择一个小赛道，持续跟踪头部产品与研究者，亲自体验产品并发布可验证的研究记录。先坚持一百天，再评价结果。
