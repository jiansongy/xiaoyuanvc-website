# 第一章：公链基础篇

## 本章导读

加密货币之所以难入门，是因为它涉及计算机科学、网络技术、全球金融经济、投资理财，以及各国政策管制等多个领域，纠缠不清且时刻变化。

相比人工智能，加密货币更得到年轻一代的青睐。原因是加密货币的"暴富品的小白可及性"更好——它不看你的出身和地点，非常公平。暴富品必须具备三大特性：由共识驱动（是注意力资产而非现金流资产）、能拥有资产权（可以当股东、享受资本升值）、常人难认知（看不见、看不起、看不懂、来不及）。

公链（Public Blockchain）是一种完全开放、去中心化的区块链网络，任何人都可以自由加入、读取数据、发送交易，并参与共识过程。其核心特征包括去中心化、开放性、透明性和不可篡改性。本课将带你从比特币出发，逐步理解整个公链世界的技术演进。
