## 区块链技术

其实是先有了比特币，人们后来才把实现了比特币的底层技术，称为区块链（BlockChain）技术。

### 创新之处

互联网让信息可以自由传播，但它传递的只是**复制品。**图片、视频、邮件都能无限复制。可是真正的**价值**，比如100元人民币，是不能被复制的。在传统互联网里，价值流动必须依赖，银行或微信支付这样的中介，由中介来记账才能实现。中本聪发明了比特币，彻底改变了这一切。

基于区块链技术的“挖矿”（由矿工们进行去中心化记账），第一次让网络本身，就能**自动产生并分配价值**。每个矿工都在用计算力，帮助网络记账、验证交易，系统就自动奖励他们加密货币。这样一来，**贡献者被激励、网络被维护、信任被建立**——没有任何中心化机构。它反映了一种全新的生产关系。

这就是“价值网络”的核心：网络不只是传递信息，而是直接在**传递、创造和分配**价值。我们可以说“加密货币带来了价值网络”，让这个世界变得不同了。

### 技术原理

根据蒋勇写的《**白话区块链**》，本质上区块链是通过丢骰子（共识算法）来确定记账人的，去中心化公开账本，被骰子选中的记账人，作为矿工打包了交易，可以获得代币奖励（这就是代币的发行过程）。

有同学问：这个丢骰子是随机的吗？我回答：是随机的，但要遵循共识算法（比如 PoW 或 PoS），详细的内容，请去阅读《白话区块链》这本书，因为下图就是从该书中做的截图。

> **图示说明：** 图片展示了区块链中“丢骰子”确定记账人的概念。画面中有四个账本，分别由李四、张三、赵六、王五持有。账本间用箭头连接，其中张三的账本指向骰子，骰子再指向李四的账本。这与上下文提到的区块链通过共识算法（如PoW或PoS）确定记账人，被骰子选中的记账人作为矿工打包交易并获得代币奖励相呼应，直观呈现了“丢骰子”这一共识机制。

### 区块链的数据结构

> **图示说明：** 这张图展示了区块链的数据结构，呈现三个依次关联的区块，每个区块均由区块头和区块主体构成。区块1头的箭头指向区块2头，区块2头的箭头指向区块3头，以此体现区块链首尾相连的特性。每个区块头都包含前一个区块头哈希，用于实现区块链的不可篡改关联，这一结构契合了区块链无法篡改的本质。同时，每个区块的主体部分对应其交易事务，经梅克尔根整合后录入区块，完整呈现了区块链数据的构建模式。

区块链的本质是：**无需许可、无需信任、公开透明、无法篡改**。

人人都拥有个人资产的控制权，但是无人拥有网络上共识的控制权，因为由随机产生的人（矿工）来记账。代币是由在网络中的共识算法，进行控制而有一个公认的状态（账本），而不存在任何个体计算机上。

### 如何理解区块链

比特币（基于区块链）是一种全新的货币范式，不由国家来发行，也能保证“其数字有价值”，前提是要充分理解其“去中心化”的本质。因为这个概念太复杂，所以对任何人来说，这个理解都需要一个消化过程。最好的理解方式是：给自己身边的亲朋好友去讲述这个区块链的原理，和反对意见进行辩论，道理是越辩越明的。

我10年前在清华，带过一个大学生，他是学生物专业的。我的创业训练营，带他进入了数字创业领域，现在已经是某个加密货币交易所的 CTO。一开始他被我的教学方式（像打开消防栓一样扑面而来的信息洪流）给搞蒙了。

但是我点燃了他学习的热情，还教了他一个自学方法：**RSA（Read、Search、Ask）**。其实任何领域的“名词术语”，其实都是纸老虎。首先不要怕，其次用好 ChatGPT 或者豆包（比如请 AI 把你当做初中学生解释什么是“POW”），最后有难题就到社群问导师，都能迎刃而解。

真正你需要学习的是**学习能力。**我每天都在推特和油管上自学，刷新对加密货币的前沿认知。悲观者正确，但是乐观者成功。我作为导师的价值，是激发你对加密货币的向往，并给你提供一个结构化、系统化的入门指引，让你别迷路了。

## 建议从做 KOL 起步

做**币圈 KOL** 的七原则

1. 选平台：X+Telegram+Youtube，相比国内的平台，不容易被封禁
2. 选赛道：比特币定投、永续期货交易所、迷因币发射台和预测市场等等
3. 选对标：本赛道中 Top 10的创新产品和 Top10 的 KOL
4. 做研究：深度探索这10个产品的源代码、用户体验并输出报告
5. 做通讯：综合这些 KOL 的舆论动态，发布每日赛道通讯
6. 混圈子：主动出击+被动吸引，真诚接待和帮助每个网友
7. 百日更：在坚持日更到100天完成之前，不计产出、只管投入！
