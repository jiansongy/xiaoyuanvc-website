# 第二章：实务操作篇

## 本章导读

人教人，教不会。事教人，一次会。实践是最好的老师，所以这一课我们学习"在币圈中实际做什么"。

如果用汽车来比喻，第一章的理论（公链）介绍了发动机有三种动力机制，比如燃油（PoW 共识算法）、电能（PoS 共识算法）、氢能等。而第二章讲实务，相当于教汽车驾驶——学习操控汽车和遵守交通规则。两章的侧重点完全不同。

MetaMask 所体现的加密原教旨主义，对普通用户来说有**三大挑战**：助记词、出入金和链上手续费（Gas）。如何克服这三大挑战？建议从中心化交易所（CEX）的服务（比如币安和 OKX）开始入手。本章将手把手教你从开户到安全管理的全套实务操作。

::: warning 投资提醒
本课程中提及的所有代币，都是出于教育目的、仅作信息提供，不构成任何投资建议。投资有风险，你有可能损失掉全部的本金。
:::

## 三大挑战详解

在深入课程之前，先理解这三个必须克服的障碍：

| 挑战       | 这是什么                                        | 为什么难                                    | 本章哪课解决       |
| ---------- | ----------------------------------------------- | ------------------------------------------- | ------------------ |
| **助记词** | 12 个英文单词组成的密码，是你加密资产的唯一凭证 | 丢了就永远找不回来，没有"忘记密码"按钮      | 2.2 钱包基础       |
| **出入金** | 把人民币换成加密货币（入金），或反过来（出金）  | 国内银行不直接支持，需要通过 P2P 或境外渠道 | 2.1 交易所使用     |
| **Gas 费** | 在区块链上做任何操作都要付的"手续费"            | 以太坊 Gas 费有时高达几十美元，且不能预测   | 2.1 + 2.3 安全防骗 |

::: tip 本章的学习策略
**从中心化交易所（CEX）开始**，而不是直接用钱包。交易所帮你屏蔽了大部分技术复杂度（不用管助记词、不用付 Gas 费），让你先专注于学习交易本身。等熟悉了再慢慢过渡到链上钱包操作。
:::

## 核心问题

1. **如何安全地买入第一笔加密货币？** 交易所开户和入金的完整流程是什么？

3. **区块链世界有哪些常见骗局？** "黑暗森林"中如何保护自己？
4. **热钱包和冷钱包如何搭配使用？** 什么资产放哪里最合适？
