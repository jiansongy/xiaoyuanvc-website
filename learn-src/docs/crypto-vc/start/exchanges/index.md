## 核心思路

### CEX vs DEX

::: info 一句话区分
**CEX**（中心化交易所）像银行，你把钱交给它保管，它帮你撮合交易。**DEX**（去中心化交易所）像自动售货机，你自己投币取货，不需要中间人。
:::

| 对比项 | CEX（中心化交易所） | DEX（去中心化交易所） |
|--------|-------------------|---------------------|
| **代表** | 币安、Coinbase | Uniswap、Raydium |
| **注册** | 需要 KYC（实名认证） | 不需要，钱包连接即可 |
| **资产保管** | 交易所保管（你信任它） | 自己保管（你的钱包） |
| **交易速度** | 快（毫秒级） | 取决于链上速度 |
| **法币入金** | 支持（银行卡、P2P） | 不支持（需要先有加密资产） |
| **适合** | 新手入门、大额交易 | 有经验的用户、链上代币交易 |

**新手建议**：先用 CEX 买入你的第一笔加密货币，等熟悉后再尝试 DEX。

### 为什么选币安

币安（Binance）是全球最大的加密交易所之一。2025 年数据：

- CEX 年度现货交易量 $19.7 万亿（同比 -12.5%）
- 加密总市值约 $3 万亿
- BTC 占比约 57%
- 币安在交易量和用户数上持续领先

::: warning 交易所也有风险
2014 年 Mt.Gox 倒闭（85 万 BTC 消失）、2022 年 FTX 崩盘，都是血的教训。建议：
- 不要把所有资产放在交易所
- 大额资产转到自己的钱包
- 只在需要交易时才把资金放在交易所
:::

## 🎒 开始前的准备

::: warning 你需要准备
- 一部手机 + 一台电脑
- 身份证或护照（用于 KYC 认证）
- 一个常用邮箱
- 用于绑定的手机号码
- Google Authenticator 或类似的 2FA 应用
:::

## 跟我做

### 第 1 步：注册币安账号

**为什么**
注册是使用交易所的第一步。

1. 打开 [binance.com](https://www.binance.com)（注意核对网址）
2. 点击"注册"
3. 选择"使用邮箱注册"
4. 输入你的邮箱地址，设置强密码
5. 完成邮箱验证（查看收件箱，输入验证码）

::: danger 安全提醒
- 只从 binance.com 官网注册
- 密码不要和其他平台重复
- 使用专门的邮箱（不要用日常邮箱）更安全
:::

**你应该看到**：注册成功，进入币安首页

### 第 2 步：完成 KYC 认证

**为什么**
KYC（Know Your Customer）是交易所的实名认证要求。不完成 KYC 无法入金和交易。

1. 进入"身份认证"页面
2. 选择你的国家/地区
3. 上传身份证正反面照片（或护照）
4. 完成人脸识别验证
5. 等待审核（通常几分钟到几小时）

**你应该看到**：认证状态变为"已验证"

::: tip KYC 是合规要求
很多人担心隐私问题。KYC 是金融监管的标准流程，正规交易所都要求。如果你非常在意隐私，可以后续学习使用 DEX（不需要 KYC）。
:::

### 第 3 步：设置安全措施

**为什么**
交易所账号里会有钱，安全设置是必须的。

1. **绑定手机号**：进入安全设置，绑定你的手机号
2. **开启 2FA**：
   - 下载 Google Authenticator（手机应用商店搜索）
   - 在币安安全设置中选择"Google Authenticator"
   - 用 Google Authenticator 扫描二维码
   - 输入 6 位验证码完成绑定
3. **设置资金密码**：不同于登录密码，用于提现等操作
4. **开启防钓鱼码**：设置一个自定义字符串，币安发给你的邮件都会包含这个码

**你应该看到**：安全设置页面显示所有安全项都已开启

::: danger 2FA 备份码要保管好
Google Authenticator 绑定时会给你一串备份码。如果手机丢了或换手机，需要用备份码恢复。把备份码手抄在纸上，和钱包助记词一样安全保管。
:::

### 第 4 步：入金

**为什么**
有了账号之后，需要把法币（人民币/美元）充进去才能买币。

常见入金方式：
- **P2P 交易**：和其他用户直接买卖，支持支付宝、微信、银行卡
- **银行卡购买**：直接用信用卡/借记卡购买（可能有手续费）
- **加密货币转入**：如果你已有其他交易所的加密资产，可以转入

以 P2P 为例：
1. 进入"买币" → "P2P 交易"
2. 选择你要买的币（建议先买 USDT）
3. 选择一个信誉好的卖家（看成交量和好评率）
4. 输入金额，选择支付方式
5. 按照提示完成付款
6. 确认收到 USDT

**你应该看到**：币安账户余额出现你购买的 USDT

::: tip 为什么先买 USDT？
USDT 是稳定币，1 USDT ≈ 1 美元。先买 USDT，然后用 USDT 购买 BTC、ETH 等加密货币，是最常见的操作流程。
:::

### 第 5 步：购买你的第一笔加密货币

**为什么**
这是你正式进入加密世界的标志性一步。

1. 进入"交易" → "现货交易"
2. 搜索交易对，比如 "BTC/USDT"
3. 选择"市价单"（按当前市场价格买入）
4. 输入你想买入的金额（比如 10 USDT）
5. 点击"买入 BTC"
6. 确认订单

**你应该看到**：你的账户余额出现了 BTC（金额可能很小，比如 0.0001 BTC）

::: warning 从小额开始
第一次买币建议金额不超过 100 元人民币。目的是熟悉流程，不是投资。等你完全弄懂了再增加金额。
:::

## 踩坑提醒

::: danger P2P 交易注意事项
- 只选择成交量高、好评率高的商家
- 不要在交易所之外的渠道完成付款
- 付款后等对方放币，不要催促
- 遇到问题用币安的申诉功能，不要私下解决
:::

::: warning 不要在交易所放太多钱
交易所是用来交易的，不是用来存钱的。买完币之后，大额资产建议转到自己的钱包（MetaMask 或 Phantom）。记住上一课学的："Not your keys, not your coins"。
:::

::: warning 注意手续费
- P2P 交易：通常免手续费，但汇率可能略高
- 现货交易：通常 0.1% 手续费
- 提现到钱包：需要支付网络手续费
:::

## 本课小结

这节课你完成了"买币"的全流程：

- **CEX vs DEX**：CEX 适合新手（需要 KYC），DEX 适合进阶用户（钱包直连）
- **币安注册**：注册 → KYC → 安全设置 → 入金 → 交易
- **安全第一**：2FA、资金密码、防钓鱼码一个都不能少
- **从小额开始**：第一次买币重在熟悉流程，不在金额大小
- **交易所 ≠ 钱包**：大额资产转到自己的钱包
