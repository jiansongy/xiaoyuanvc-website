## 核心思路

### 不可能三角

::: info 什么是不可能三角？
区块链的**不可能三角**（Blockchain Trilemma）指的是：**去中心化**、**安全性**、**可扩展性**，三者不可能同时完美实现。任何公链都必须在这三者之间做取舍。
:::

```
                    去中心化
                   ╱        ╲
                  ╱          ╲
                 ╱   不可能    ╲
                ╱    三角      ╲
               ╱                ╲
              安全性 ————————— 可扩展性
```

- **去中心化**：节点越多越分散，越不容易被控制
- **安全性**：网络越难被攻击，资产越安全
- **可扩展性**：处理速度越快，能支持的用户越多

想同时做到三个"满分"在目前的技术下做不到，所以每条公链都选了不同的侧重点。

### 三大公链的取舍

| 维度 | 比特币 | 以太坊 | Solana |
|------|--------|--------|--------|
| **侧重** | 去中心化 + 安全 | 安全 + 去中心化 | 可扩展性 + 安全 |
| **牺牲** | 速度（TPS 仅 7） | 速度（TPS 15-30） | 去中心化程度 |
| **定位** | 数字黄金，价值存储 | 智能合约平台 | 高性能应用平台 |
| **共识** | PoW | PoS | PoH + PoS |
| **出块** | ~10 分钟 | ~12 秒 | ~0.4 秒 |
| **费用** | $1-10 | $0.5-100+ | <$0.01 |
| **节点数** | ~15,000+ | ~7,000+ | ~2,000+ |
| **核心优势** | 最去中心化、最安全 | 生态最丰富 | 速度最快、费用最低 |

::: tip 没有"最好"的公链
就像没有"最好的交通工具"一样：飞机最快但最贵，自行车最便宜但最慢，汽车居中。选什么取决于你要去哪、预算多少。公链也一样。
:::

### 2025 年三大代币表现

| 代币 | 年末价格 | 2025 年涨跌 | 市值排名 |
|------|---------|-------------|---------|
| BTC | $87,520 | -6.4% | #1 |
| ETH | $2,967 | -11.1% | #2 |
| SOL | $124.52 | -34.3% | TOP 10 |

三个都跌了，但幅度差很多。为什么？

- **BTC 跌最少**：作为"数字黄金"，避险属性强，机构持仓多（ETF、SBR），下跌时有支撑
- **ETH 居中**：生态强但面临竞争压力，L1 收入份额从垄断降到 17%
- **SOL 跌最多**：2024 年涨幅巨大，回调幅度也大。但生态指标（TVL、交易量）反而大幅增长

### 和传统资产对比

2025 年不只是加密市场在调整。来看看各类资产的表现：

| 资产 | 2025 年全年回报 |
|------|---------------|
| 黄金 | +62.6% |
| 纳斯达克 | +20.5% |
| 标普 500 | +16.6% |
| BNB | +23% |
| BTC | -6.4% |
| ETH | -11.1% |
| SOL | -34.3% |

::: warning "有史以来最两极分化的一年"
2025 年被 Messari 称为"有史以来最两极分化的一年"：华尔街经历了最好的年份之一（黄金大涨、股市稳健），而加密散户的情绪降到了冰点（恐惧贪婪指数一度降至 10）。

教训：加密资产不总是涨的，不要把鸡蛋放一个篮子里。
:::

### 加密市场全景

2025 年末的加密市场整体格局：

| 指标 | 数据 |
|------|------|
| 加密总市值 | $3.0 万亿 |
| BTC 市值占比 | 57.4% |
| BTC + ETH 合计占比 | ~65% |
| 稳定币总市值 | $3110 亿（+48.9%） |
| DeFi TVL | $1167 亿（年末） |

BTC 仍然是绝对的"老大哥"，占据超过一半的市场份额。但稳定币的增长是最快的（+48.9%），说明更多资金正在通过稳定币进入加密世界。

### 如何选择关注的公链

给初学者的建议：

| 你的兴趣 | 重点关注 | 原因 |
|----------|---------|------|
| 长期投资 | BTC | 最安全、最被机构认可 |
| DeFi 和应用 | ETH | 生态最丰富 |
| 高频交易和新项目 | SOL | 速度快、费用低、热点多 |
| 全面了解 | 三个都关注 | 它们代表了三种不同的技术路线 |

## 跟我做：在 CoinGecko 查看市场数据

### 第 1 步：打开 CoinGecko

**为什么**
CoinGecko 是最常用的加密市场数据网站之一，免费且数据全面。

打开：[coingecko.com](https://www.coingecko.com)

**你应该看到**：首页显示加密货币排行榜、总市值、BTC 占比等

### 第 2 步：查看 BTC、ETH、SOL 的实时数据

**为什么**
把课上学的数据和实时数据对比，建立直觉。

搜索并点击 Bitcoin、Ethereum、Solana，分别查看：
- 当前价格
- 24 小时 / 7 天 / 30 天涨跌
- 市值和排名
- 历史价格图表

**你应该看到**：三个代币的价格走势图，以及各种市场指标

### 第 3 步：查看总市值和 BTC 占比

**为什么**
感受加密市场的整体规模和 BTC 的主导地位。

在 CoinGecko 首页或搜索 "total market cap" 查看：
- 加密总市值
- BTC 占比（Dominance）

**你应该看到**：总市值在万亿美元级别，BTC 占比通常在 50-60% 之间

### 第 4 步：对比三大代币的年度表现

**为什么**
用数据而非感觉来判断市场。

在每个代币页面切换到"1Y"（一年）视图，对比：
- 谁的波动最大
- 谁相对抗跌
- 走势是否相关

**你应该看到**：三条线整体趋势相似（因为市场相关性），但幅度差异明显

## 踩坑提醒

::: warning 误区一："哪个币涨得多就买哪个"
过去的涨幅不代表未来。SOL 2024 年涨得最多，2025 年也跌得最多。分散投资比押注单一代币更理性。
:::

::: warning 误区二："加密货币都跌了，是不是要完了"
2025 年是加密市场 2022 年以来首次下跌年，但总市值仍有 $3 万亿。市场有涨有跌很正常，不要被短期波动影响长期判断。
:::

::: warning 误区三："BTC 最保值，只买 BTC 就行"
BTC 确实波动最小，但把 100% 资金放在任何单一资产上都不明智。即便是传统投资，也讲究资产配置。
:::

## 本课小结

这节课我们站在高处看了一遍加密市场的全景：

- **不可能三角**：去中心化、安全、可扩展性，三者不能兼得
- **BTC**：最去中心化最安全，但最慢。定位：数字黄金
- **ETH**：生态最丰富，但费用高。定位：智能合约平台
- **SOL**：最快最便宜，但去中心化程度较低。定位：高性能应用
- **2025 年表现**：三大代币都下跌，黄金是年度最佳传统资产
- **市场格局**：总市值 $3 万亿，BTC 占 57.4%，稳定币增长最快
