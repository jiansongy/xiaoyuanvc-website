# 第四章：稳定币、DeFi、RWA 与 NFT

公链和智能合约是基础设施，本章转向应用：稳定币把法币价值带上链，DeFi 用代码重组金融服务，RWA 连接现实资产，NFT 则探索可验证的数字所有权。

::: warning 数据说明
本章中的规模、费用和时间均来自课程底稿的阶段性观察或机制示例，不是实时报价。链上费用、市场规模和产品规则会变化，使用前请到官方数据源复核。
:::

| RWA | 现实资产的链上映射 | 代币化国债、信贷、股票凭证 | 法律权利、托管、赎回与合规 |
| NFT | 唯一数字资产与所有权凭证 | ERC-721、CryptoPunks | 估值、版权、流动性与平台依赖 |

## 稳定币：加密经济的现金

稳定币是试图锚定法币或其他资产价格的加密资产。它降低了 BTC、ETH 等资产波动对交易和支付的影响，因此被广泛用于交易对、跨境结算和 DeFi。

稳定币像物流行业的集装箱：标准化之后，资产可以在不同钱包、交易平台和协议之间更高效地流动。

### 主要类型

| 类型 | 机制 | 例子 | 需要重点验证 |
| --- | --- | --- | --- |
| 法币储备型 | 发行方持有现金或短期资产 | USDT、USDC | 储备透明度、赎回、冻结权 |
| 加密资产抵押型 | 超额抵押并由智能合约管理 | DAI | 抵押品波动、清算与治理 |
| 其他机制型 | 依靠组合资产或算法维持锚定 | 各类新协议 | 压力情境下是否会死亡螺旋 |

### 链上转账与传统电汇示意

| 网络或系统 | 课程底稿中的估算成本 | 估算结算时间 |
| --- | ---: | --- |
| Solana 稳定币转账 | 约 0.01 美元 | 约 0.4 秒到数秒 |

## DeFi：用智能合约重组金融服务

DeFi（Decentralized Finance）把交易、借贷、质押和资产管理写进智能合约。它可以 7×24 小时运行、允许不同协议组合，但“代码即规则”也意味着漏洞可能直接变成资金损失。

### 主要类别

| 类别 | 解决的问题 | 代表机制 |
| --- | --- | --- |
| DEX | 不依赖中心订单撮合来换币 | AMM、链上订单簿 |
| 借贷 | 在资金池中完成抵押借款 | 动态利率、清算 |
| 质押 | 为网络安全或协议服务提供资本 | 原生质押、流动性质押 |
| 跨链桥 | 在不同网络间映射或传递资产 | 锁定铸造、消息验证 |
| 收益与资产管理 | 组合多个协议策略 | Vault、收益聚合 |

在 [DefiLlama Categories](https://defillama.com/categories) 可以看到不同类别的 TVL、协议数量和变化。TVL 只是锁定资产规模，不等于收入、用户价值或安全性。

## AMM：没有传统做市商怎样换币

传统交易所用订单簿撮合买卖双方；AMM（自动做市商）用资金池和公式持续报价。经典常数乘积模型是：

**x × y = k**

其中 `x` 和 `y` 是池中两种资产的储备，`k` 在忽略手续费时保持不变。当用户放入更多 `x` 并取出 `y`，池中比例变化，价格也随之变化。

| 角色 | 做什么 | 承担什么风险 |
| --- | --- | --- |
| 交易者 | 与资金池交换资产 | 滑点、价格影响、恶意代币 |
| 流动性提供者 | 同时存入两种资产 | 无常损失、合约和价格风险 |
| 协议 | 维护定价、手续费和路由规则 | 代码漏洞、治理与前端风险 |

### 教学用伪代码

```solidity
function swapAForB(uint amountAIn) returns (uint amountBOut) {
    uint k = reserveA * reserveB;
    reserveA += amountAIn;
    amountBOut = reserveB - (k / reserveA);
    reserveB -= amountBOut;
}
```

真实协议还必须处理 ERC-20 转账、手续费、精度、滑点、重入攻击、预言机和权限等问题，不能直接使用这段简化代码部署资金。

### Uniswap 的创业启示

Hayden Adams 从机械工程转向自学 Solidity，把恒定乘积公式做成极简交易协议；在社区与以太坊生态支持下，Uniswap 发展为重要 DeFi 基础设施。案例说明：清晰机制、开放代码和持续执行，可以让小团队挑战成熟金融流程。

可阅读 [Uniswap Docs](https://docs.uniswap.org/)；如果要观察产品，只使用测试网、小额实验钱包，并在签名前检查授权额度。

## 借贷与闪电贷

以 Aave 为代表的借贷协议使用“点对池”：存款人把资产放入资金池，借款人提供抵押物，利率由供需曲线变化。当抵押率不足时，协议按规则清算。

闪电贷利用区块链交易的原子性：借款、操作和还款必须在同一笔交易内全部成功，否则整体回滚。它能提高资本效率，也可能被攻击者用于放大预言机或合约漏洞。

## RWA：现实资产代币化

RWA（Real World Assets）是把政府债券、房地产、私人信贷、大宗商品或股票相关权利，通过代币和智能合约在链上表达与流转。

它可能带来：

- 7×24 小时交易与更快结算
- 碎片化持有与更低参与门槛
- 与 DeFi 协议组合的可编程性
- 更透明的持仓与转移记录

但代币不是现实资产本身。研究 RWA 时必须回答：底层资产由谁持有、代币代表股权还是合同债权、是否有投票与分红权、如何赎回、哪国法律管辖、托管方违约怎么办。

课程底稿中的 bStocks 案例正好说明这种差异：股票代币可以跟踪价格和经济收益，却不一定赋予底层公司的直接股权或投票权。界面上像“股票”，法律上可能是完全不同的产品。

## NFT：数字所有权

NFT（Non-Fungible Token）是不可相互等价替换的代币。BTC 或普通 ERC-20 代币通常是同质化的；每个 ERC-721 NFT 则有独立编号和元数据。

| 类比 | 同质化 | 非同质化 |
| --- | --- | --- |
| 现实世界 | 同面额现金 | 艺术品、收藏品、门票 |
| 链上 | BTC、USDC、ERC-20 | CryptoPunks、链上艺术、游戏资产 |

复制 NFT 对应的图片，不等于获得链上所有权记录。但链上所有权也不自动等于版权、商标权或现实世界使用权，这些权利仍取决于项目条款和法律合同。

评价 NFT 时可以分四层：内容与文化、稀缺规则、社区与用途、交易流动性。价格主要由供需和共识驱动，可能剧烈波动甚至归零。
