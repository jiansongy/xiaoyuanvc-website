# 第四章：文化篇

## 本章导读

经过前三章（公链、实务、金融），本章来学习"加密文化"。加密文化属于**注意力资产**。

注意力资产和现金流资产有着完全不同的投资逻辑。现金流资产由未来现金流的风险折现决定其客观价值；而注意力资产没有客观价值，只有主观价值。巴菲特为什么不愿意投资比特币？因为他认为比特币不像股权或土地等生产性资产，可以产生现金流。其实注意力资产（比如比特币、黄金和艺术品）虽然不产生现金流，但它们凝聚了人类共识——在当今注意力稀缺的时代，也很有价值。

本课介绍两种加密文化（注意力资产）：**"NFT"和"Meme"**。注意力资产可能是"吹泡沫、纯炒作和割韭菜"。让我们先别做武断结论，来详细了解这两者，你再自己决定，是否值得为"注意力资产"分配你宝贵的注意力。

## 关键概念：注意力资产 vs 现金流资产

在进入具体课程之前，先理解本章最核心的一组概念：

| 类型           | 定义                         | 价值来源                       | 举例                                     |
| -------------- | ---------------------------- | ------------------------------ | ---------------------------------------- |
| **现金流资产** | 能产生持续收入的资产         | 未来现金流的折现价值（可计算） | 股票（分红）、房产（租金）、债券（利息） |
| **注意力资产** | 价值来自人类共识和稀缺注意力 | 主观共识（无法精确计算）       | 黄金、艺术品、比特币、NFT、迷因币        |

**为什么这个区分重要？** 因为两种资产的投资逻辑完全不同：

- 现金流资产可以用公式算出"值多少钱"（DCF 估值）
- 注意力资产无法用公式算，价值取决于"多少人相信它值钱"

巴菲特不投资比特币，正是因为他只投资现金流资产。但这并不意味着注意力资产没有价值——黄金几千年来都是注意力资产，至今仍是全球最重要的储值工具之一。

1. **注意力资产和现金流资产的本质区别是什么？** 巴菲特的批评有没有道理？

3. **迷因币为什么是"链上彩票"？** 它的定价机制和传统资产有何不同？
