# 第五章：Perp DEX、预测市场与 Crypto AI

加密行业的创新不断变化。本章选择三个能够代表产品前沿的方向：去中心化永续合约交易所、预测市场，以及用开放市场重新组织 AI 生产的 Crypto AI。

::: danger 高风险章节
永续合约和预测市场可能涉及杠杆、清算、赌博或衍生品监管，不适合零基础用户进行真实交易。本章只解释机制与创业问题；请根据所在地法律判断能否访问相关产品，不要绕过限制。
:::

## 去中心化永续合约交易所

先拆开两个概念：

- **DEX**：用户通过钱包和链上规则交易，不把全部资产与账本控制交给中心平台。
- **Perp**：没有固定到期日的永续合约，允许做多或做空，并通过保证金、资金费率和清算机制维持仓位。

组合起来，Perp DEX 就是把永续合约的撮合、保证金和结算尽可能搬到可验证系统中的交易平台。

| 概念 | 含义 | 主要风险 |
| --- | --- | --- |
| 做多 | 价格上涨时获利，反向时亏损 | 判断错误、强制平仓 |
| 做空 | 价格下跌时获利，反向时亏损 | 损失放大、极端行情 |
| 杠杆 | 用较少保证金控制更大名义仓位 | 小幅波动即可触发清算 |
| 资金费率 | 多空双方定期支付以贴近现货价格 | 长期持仓成本变化 |
| 清算 | 保证金不足时系统强制关闭仓位 | 本金快速归零、滑点 |

杠杆会同比放大收益和损失。10 倍杠杆下，标的向不利方向波动约 10%，理论上就可能耗尽保证金，实际清算还受费用、维持保证金和价格冲击影响。

## Hyperliquid 案例

[Hyperliquid](https://app.hyperliquid.xyz/) 是具有代表性的 Perp DEX。它试图同时提供中心化交易平台般的速度，以及链上系统的透明与可验证性。

课程底稿强调了三个产品特点：

- 为交易构建高性能链上执行环境，降低延迟。
- 交易本身不要求用户逐笔支付传统链上 Gas，但仍有 maker / taker 等交易费用。
- 订单、成交和账户状态比传统中心化平台更容易公开核验。

### 为什么值得创业者研究

| 过去的取舍 | Hyperliquid 的尝试 | 仍要追问的问题 |
| --- | --- | --- |
| CEX 快，但账本与托管不透明 | 提供接近 CEX 的交易体验 | 验证者、前端和升级权限是否集中 |
| DEX 透明，但常受速度与费用限制 | 自建执行与流动性体系 | 跨链桥、预言机和智能合约是否安全 |
| 传统市场有交易时段和上新流程 | 探索 24/7 的全球资产市场 | 合规、资产发行和市场操纵怎样治理 |

Hyperliquid 通过 HIP-3 等机制探索把股票、商品、外汇等更多资产做成链上永续市场。这代表“万物交易所”的产品方向，但在机构合规、产业套保与市场深度上，仍不能简单等同于 CME 等成熟市场。

### 只读理解交易界面

无需连接钱包，也可以观察一个永续市场的关键组件：

1. 交易对和指数价格
2. 买卖订单簿与最近成交
3. 市价单、限价单与预估滑点
4. 杠杆、保证金和清算价格
5. 资金费率、未平仓量和成交量
6. 止盈止损与仓位变化

研究目标是看懂风险传导，而不是马上开仓。

## 预测市场：把观点变成概率

预测市场为一个可验证的未来事件创建“是 / 否”或多个结果代币。参与者用资金表达判断，市场价格聚合分散信息，事件结束后按预先写明的规则结算。

| 阶段 | 机制 | 关键问题 |
| --- | --- | --- |
| 定义事件 | 写清标题、期限和结果条件 | 条件是否明确、可验证 |
| 交易结果 | 买卖不同结果代币 | 价格是否真能代表概率 |
| 引入事实 | 预言机把链下结果送上链 | 数据源是否可靠、中立 |
| 结算 | 正确结果兑付，错误结果归零 | 争议和异常如何处理 |

如果“是”代币价格为 0.70 美元，常被解释为市场隐含概率约 70%。这不是科学意义上的确定概率，还会受到手续费、流动性、参与者结构和大户交易影响。

## Polymarket 案例

[Polymarket](https://polymarket.com/) 用区块链、稳定币和预言机提供政治、宏观经济、科技和流行文化等事件市场。它的产品价值主要体现在：

- 用价格持续聚合不同参与者的信息
- 让市场规则、交易与结算过程更可验证
- 为媒体、研究者和机构提供实时概率信号

但它也面对监管、博彩属性、预言机争议、市场操纵、内部信息和冷启动流动性等挑战。使用前必须查看所在地规则；不要把市场价格当作确定事实。

### 如何只读分析一个市场

1. 先读标题、完整规则、截止时间和结果来源。
2. 检查市场深度、交易量、买卖价差和历史价格。
3. 分清“事件发生概率”和“当前代币成交价格”。
4. 查找可能改变判断的新信息，以及市场尚未计入的反例。
5. 预演预言机争议、规则模糊或低流动性时会发生什么。

预测市场究竟更像博彩工具，还是信息基础设施，取决于事件设计、参与者用途和监管框架；这正是值得继续研究的问题。

## Crypto AI：用开放市场生产 AI

AI 的模型、GPU、数据和服务入口大量集中在少数公司。Crypto AI 试图用区块链、代币和开放市场重新组织资源：谁提供算力或模型、谁评价质量、怎样奖励贡献、数据和服务归谁控制。

这个领域常被称为 AI Crypto、Crypto AI、DeAI 或 DeFAI，术语尚未完全统一。研究重点不应是名称，而是机制是否真的解决激励、支付、所有权和开放协作问题。

## Bittensor 案例

[Bittensor](https://www.bittensor.com/) 不是一个聊天机器人或单一大模型，而是让参与者竞争生产“数字商品”的开放网络。这些商品可以是推理、GPU 算力、搜索、数据、存储、预测或 Agent 服务。

### 四个核心角色

| 角色 | 作用 | 类比 |
| --- | --- | --- |
| Subnet | 定义某类数字商品和比赛规则 | 一个专门市场或赛场 |
| Miner | 提供模型、算力、数据或服务 | 生产者 |
| Validator | 测试、比较并评价 Miner | 裁判与质量评估者 |
| TAO | 按网络规则分配激励 | 市场奖励 |

运行循环可以写成：

> Subnet 定义问题 → Miner 竞争提供服务 → Validator 评价质量 → 网络分配激励 → 更多参与者加入

它真正提出的问题是：不成立一家巨型 AI 公司，能否让全球参与者共同生产有价值的 AI？难点也同样明显：评价指标可能被博弈，激励不一定等于真实需求，代币价格也可能掩盖产品质量。

## 六大应用领域复盘

| 领域 | 核心价值 | 研究入口 |
| --- | --- | --- |
| 稳定币 | 链上现金与结算 | 储备、赎回、链分布 |
| DeFi | 可组合金融服务 | 合约、收入、TVL、风险 |
| RWA | 现实资产上链 | 法律权利、托管、流动性 |
| Perp DEX | 链上衍生品市场 | 性能、透明度、清算 |
| 预测市场 | 用价格聚合信息 | 规则、流动性、预言机 |
| Crypto AI | 开放生产数字智能商品 | 需求、评价机制、激励 |

## 十个必须会解释的概念

1. **区块链**：由分散参与者共同维护、可公开验证的账本。
2. **比特币**：把稀缺性和转账规则写入协议的加密资产网络。
3. **以太坊**：支持智能合约和 DApp 的公共计算平台。
4. **钱包**：管理私钥、地址、签名和多链交互的工具。
5. **安全**：零信任、持续验证、隔离与小额试错。
6. **智能合约**：部署在区块链上并按确定规则执行的程序。
7. **稳定币**：试图锚定法币或其他资产价格的链上资产。
8. **DeFi**：用智能合约提供交易、借贷等金融服务。
9. **Perp DEX**：把永续合约交易和结算搬到可验证系统的市场。
10. **Crypto AI**：用开放协议重组 AI 的生产、支付、所有权和协作。

## 完成教程后怎样继续

选一个应用领域，持续做四件事：体验头部产品、读官方文档和链上数据、记录支持与反对证据、定期更新自己的判断。真正的创投能力不是猜中一次价格，而是能清楚解释产品为谁解决什么问题、为什么现在出现、怎样持续创造价值，以及什么会让判断失效。
