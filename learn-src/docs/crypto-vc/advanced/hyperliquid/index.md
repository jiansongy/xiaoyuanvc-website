## 核心思路

### 什么是永续合约？

::: info 一句话定义
**永续合约**是一种没有到期日的价格合约，让你可以押注资产价格的涨跌，而不需要实际持有该资产。
:::

传统期货合约有到期日（比如"3月到期的比特币期货"），到期后必须交割。永续合约没有到期日，可以一直持有，这是它"永续"的含义。

**永续合约 vs 现货交易**：

| 对比项 | 现货交易 | 永续合约 |
|--------|---------|---------|
| 持有的是什么 | 实际的 BTC/ETH | 价格合约（不是真币） |
| 能做空吗 | 不能（只能买入） | 可以（押注下跌） |
| 杠杆 | 无（1倍） | 可选（1-100倍） |
| 盈亏来源 | 价格变化 | 价格变化 × 杠杆 |
| 风险 | 最多亏光本金 | 可能爆仓（亏光保证金） |

### 做多和做空

::: info 做多（Long）
**做多**就是押注价格会上涨。如果价格涨了，你赚钱；如果价格跌了，你亏钱。
:::

::: info 做空（Short）
**做空**就是押注价格会下跌。如果价格跌了，你赚钱；如果价格涨了，你亏钱。
:::

**举例说明**：

假设 BTC 当前价格是 $90,000：

| 操作 | 价格变化 | 结果 |
|------|---------|------|
| 做多 | 涨到 $95,000（+5.5%） | 盈利 |
| 做多 | 跌到 $85,000（-5.5%） | 亏损 |
| 做空 | 涨到 $95,000（+5.5%） | 亏损 |
| 做空 | 跌到 $85,000（-5.5%） | 盈利 |

### 杠杆：放大器

::: info 什么是杠杆？
**杠杆**让你用较少的保证金控制较大的仓位。10 倍杠杆意味着用 $100 保证金可以开 $1,000 的仓位。
:::

**杠杆的双刃剑效应**：

| 杠杆倍数 | 保证金 | 仓位大小 | 价格涨 10% | 价格跌 10% |
|---------|--------|---------|-----------|-----------|
| 1x | $1,000 | $1,000 | +$100（+10%） | -$100（-10%） |
| 5x | $1,000 | $5,000 | +$500（+50%） | -$500（-50%） |
| 10x | $1,000 | $10,000 | +$1,000（+100%） | **爆仓**（-100%） |
| 20x | $1,000 | $20,000 | +$2,000（+200%） | **爆仓**（-50%就爆） |

::: danger 爆仓是什么？
当亏损接近你的保证金时，交易所会强制平仓，你的保证金全部损失。这就是**爆仓**。杠杆越高，爆仓越容易发生。
:::

### 资金费率

永续合约有一个特殊机制叫**资金费率（Funding Rate）**：

::: info 资金费率
资金费率是多头和空头之间定期支付的费用，用于让永续合约价格和现货价格保持一致。
:::

- **正资金费率**：多头付给空头（市场看涨情绪强）
- **负资金费率**：空头付给多头（市场看跌情绪强）

资金费率通常每 8 小时结算一次。如果你长期持仓，资金费率会累积成可观的成本或收益。

### 认识 HyperLiquid

::: info HyperLiquid 是什么？
**HyperLiquid** 是目前排名第一的去中心化永续合约交易所，自建 L1 区块链，实现了 CEX 级别的性能和 DEX 级别的透明度。
:::

**HyperLiquid 的特点**：

| 特点 | 说明 |
|------|------|
| **快如闪电** | 自建 L1 区块链，交易速度极快 |
| **零 Gas 费** | 在专属链上交易，不需要支付以太坊 Gas |
| **完全上链** | 所有交易链上可查，公开透明，无法作弊 |
| **订单簿模式** | 不是 AMM，而是传统的订单簿撮合 |
| **挑战币安** | 正在挑战币安在衍生品市场的领导地位 |

**为什么 HyperLiquid 重要？**

2025 年数据显示：
- 永续 DEX 交易量增长 **346%**
- 美国大选后 11 月交易量达 **$92 亿**
- HyperLiquid 证明了 CEX 级性能 + DEX 级透明度可以兼得

### HyperLiquid vs 币安合约

| 对比项 | 币安合约（CEX） | HyperLiquid（DEX） |
|--------|---------------|-------------------|
| 资产托管 | 平台托管 | 用户自己控制 |
| 注册要求 | KYC 实名 | 连接钱包即可 |
| 交易费用 | 手续费 | 手续费（无 Gas） |
| 透明度 | 不透明 | 完全链上可查 |
| 交易速度 | 快 | 同样快 |
| 流动性 | 最高 | 快速增长中 |
| 风险 | 平台可能倒闭 | 智能合约风险 |

## 跟我做：了解 HyperLiquid 界面

::: warning 重要提示
本节仅介绍如何了解 HyperLiquid 界面，**不建议新手实际交易**。如果你决定尝试，请只用极小金额（如 $10-20），并做好全部亏损的准备。

### 第 1 步：访问 HyperLiquid

**为什么**：确保访问官方网站

1. 打开浏览器，输入官方地址：`https://app.hyperliquid.xyz/`
2. 检查网址是否正确
3. 建议收藏官方网址

**你应该看到**：HyperLiquid 的交易界面，包含价格图表、订单簿、交易面板

### 第 2 步：连接钱包

**为什么**：HyperLiquid 需要读取你的钱包

1. 点击右上角的 "Connect" 按钮
2. 选择你的钱包（MetaMask 等）
3. 确认连接

**你应该看到**：钱包地址显示在右上角

### 第 3 步：了解界面布局

**为什么**：熟悉界面才能理解交易流程

HyperLiquid 界面主要包含：

| 区域 | 功能 |
|------|------|
| **价格图表** | 显示价格走势和技术指标 |
| **订单簿** | 显示买卖挂单深度 |
| **交易面板** | 下单区域（做多/做空） |
| **持仓信息** | 显示当前持仓和盈亏 |
| **账户信息** | 显示保证金余额 |

### 第 4 步：理解交易面板

**为什么**：这是下单的核心区域

交易面板通常包含：

- **方向选择**：Long（做多）/ Short（做空）
- **订单类型**：Market（市价）/ Limit（限价）
- **杠杆设置**：1x - 50x（或更高）
- **数量输入**：要交易的合约数量
- **止盈止损**：可选的风控设置

::: tip 关键参数
- **Entry Price**：开仓价格
- **Liquidation Price**：爆仓价格
- **Margin**：所需保证金
- **Leverage**：杠杆倍数
:::

### 第 5 步：查看资金费率

**为什么**：资金费率影响持仓成本

1. 在交易界面找到 "Funding" 或 "资金费率" 显示
2. 查看当前费率和下次结算时间
3. 正费率意味着多头付给空头，负费率相反

**你应该看到**：类似 "0.01% / 8h" 的显示

## 踩坑提醒

::: warning 坑 1：高杠杆的诱惑
看到 100 倍杠杆，想着"小资金博大收益"。但 100 倍杠杆意味着价格波动 1% 就可能爆仓，BTC 日内波动 3-5% 很常见。

**应对**：新手最多用 2-3 倍杠杆，永远不要用超过 10 倍杠杆。记住：活着才能参与下一次机会。
:::

::: warning 坑 2：不设止损
开仓后不设止损，想着"再等等就会涨回来"。但市场不会因为你的期望而改变，不止损的结果往往是爆仓。

**应对**：开仓前就想好止损位，严格执行止损，不要手动取消。亏损是交易的一部分，接受它。
:::

::: warning 坑 3：重仓单一方向
把所有资金都押在一个方向。但市场可能突然反转，黑天鹅事件随时可能发生，重仓 = 一次错误就出局。

**应对**：单笔交易不超过总资金的 10%，分散风险，不要 All in，保留足够的保证金应对波动。
:::

::: warning 坑 4：忽视资金费率
长期持仓，没注意资金费率。资金费率每 8 小时结算一次，极端行情下费率可能很高，长期持仓的费率成本可能超过盈利。

**应对**：关注资金费率变化，高费率时考虑减仓，计算持仓成本时包含资金费率。
:::

::: warning 坑 5：情绪化交易
亏损后想"扳回来"，加大仓位。情绪化交易是亏损的主要原因，"报复性交易"往往导致更大亏损。

**应对**：设定每日最大亏损限额，连续亏损后停止交易休息一天，交易前制定计划严格执行。
:::

## 风险控制原则

如果你决定尝试永续合约，请牢记以下原则：

### 资金管理

| 原则 | 说明 |
|------|------|
| **只用亏得起的钱** | 永续合约资金应该是你能承受全部损失的金额 |
| **单笔风险 < 2%** | 单笔交易亏损不超过总资金的 2% |
| **总仓位 < 30%** | 不要把所有资金都用于开仓 |
| **保留应急资金** | 留足保证金应对极端波动 |

### 交易纪律

| 原则 | 说明 |
|------|------|
| **必设止损** | 每笔交易都要设止损 |
| **不追涨杀跌** | 不在情绪高涨时加仓 |
| **不频繁交易** | 减少交易次数，提高胜率 |
| **记录复盘** | 记录每笔交易，定期复盘 |
