## 核心思路

### 什么是预测市场？

**预测市场**是一种让人们对未来事件下注的市场，结果由真相决定。

::: info 简单理解
预测市场就像一个"真相交易所"。你可以买入"是"或"否"的份额，如果你的预测正确，你就能获得收益。比如："2026年美国会通过某项法案吗？"——你可以买入"是"或"否"，等结果揭晓后，正确的一方获得奖励。
:::

### 预测市场 vs 传统博彩

| 特点 | 预测市场 | 传统博彩 |
|------|---------|---------|
| 赔率设定 | 由市场供需决定 | 由庄家设定 |
| 透明度 | 链上公开透明 | 不透明 |
| 参与门槛 | 连接钱包即可 | 需要注册、KYC |
| 结算方式 | 智能合约自动结算 | 人工结算 |
| 市场类型 | 政治、科技、加密货币等 | 主要是体育 |

### 市场智慧（The Wisdom of Crowds）

预测市场的核心价值在于**市场智慧**——当大量人用真金白银下注时，市场价格往往能反映出事件发生的真实概率。

::: tip 为什么市场智慧有效？
- **真金白银**：参与者用自己的钱下注，会认真研究
- **信息聚合**：不同人掌握不同信息，市场价格聚合了所有信息
- **持续更新**：新信息出现时，价格会实时调整
- **历史验证**：研究表明，预测市场的准确率往往高于民调
:::

### Polymarket：最大的加密预测市场

**Polymarket**是目前最大的加密预测市场平台，建立在Polygon区块链上。

**平台特点**：
- 使用USDC作为交易货币
- 支持多种市场类别（政治、体育、科技、加密货币等）
- 链上透明，智能合约自动结算
- 无需KYC，连接钱包即可参与

## 2025年预测市场数据

预测市场在2025年经历了爆发式增长：

| 指标 | 2024年 | 2025年 | 变化 |
|------|--------|--------|------|
| 名义交易量 | $158亿 | $635亿 | +302.7% |
| Polymarket年交易量 | - | $273亿 | - |
| Kalshi年交易量 | - | $241亿 | - |

**关键事件**：
- 美国大选后，2025年11月单月交易量达到$92亿
- 体育博彩成为最大类别（Kalshi平台90%+的交易量来自体育）
- AI代理开始参与预测市场，成为新的参与者类型

::: info 为什么2025年爆发？
1. **美国大选**：政治事件吸引了大量关注和资金
2. **监管明确**：部分地区对预测市场的监管逐渐清晰
3. **用户体验改善**：平台操作更加简单
4. **传统博彩融合**：体育博彩与加密预测市场开始融合
:::

## 如何解读赔率

在Polymarket上，价格代表市场认为事件发生的概率。

**示例**：
- 如果"是"的价格是$0.70，意味着市场认为该事件有70%的概率发生
- 如果"否"的价格是$0.30，意味着市场认为该事件有30%的概率不发生
- "是"和"否"的价格之和通常接近$1.00

**收益计算**：
- 如果你以$0.70买入"是"，事件发生后，你获得$1.00，收益率约43%
- 如果你以$0.30买入"否"，事件不发生后，你获得$1.00，收益率约233%

::: warning 注意
高收益意味着高风险。$0.30的"否"份额收益率高，是因为市场认为它发生的概率低。
:::

## 跟我做：体验Polymarket

### 第1步：访问Polymarket

**为什么**
先熟悉平台界面，了解有哪些市场类别。

**操作**
1. 打开浏览器，访问 https://polymarket.com/
2. 浏览首页，查看热门市场
3. 注意不同的市场类别：政治、体育、科技、加密货币等

**你应该看到**：
- 热门市场列表
- 每个市场的当前赔率
- 交易量和参与人数

### 第2步：连接钱包

**为什么**
连接钱包后才能查看详细信息和参与交易。

**操作**
1. 点击右上角的"Connect Wallet"
2. 选择MetaMask或其他支持的钱包
3. 确认连接请求
4. 确保钱包切换到Polygon网络

**你应该看到**：
- 钱包地址显示在右上角
- 可以查看自己的USDC余额

### 第3步：浏览市场类别

**为什么**
了解Polymarket上有哪些类型的预测市场。

**操作**
1. 点击顶部导航栏的不同类别
2. 浏览"Politics"（政治）、"Sports"（体育）、"Crypto"（加密货币）等
3. 选择一个感兴趣的市场，点击进入详情页

**你应该看到**：
- 市场问题描述
- 当前"是"和"否"的价格
- 交易量和流动性
- 结算规则说明

### 第4步：查看赔率和市场深度

**为什么**
理解市场价格如何反映概率。

**操作**
1. 在市场详情页，查看"是"和"否"的当前价格
2. 查看订单簿（Order Book），了解买卖深度
3. 查看历史价格走势图
4. 阅读市场的结算规则

**你应该看到**：
- 价格图表显示市场预期的变化
- 订单簿显示不同价格的买卖单
- 结算规则说明何时、如何确定结果

### 第5步：（可选）小额下注

**为什么**
通过实际操作加深理解。

::: danger 风险提示
预测市场是高风险活动。只用你亏得起的钱参与，建议首次尝试不超过$10。
:::

**操作**
1. 选择一个你有信心的市场
2. 决定买入"是"还是"否"
3. 输入金额（建议$5-10）
4. 确认交易，支付Gas费
5. 等待结果揭晓

**你应该看到**：
- 交易确认后，你的持仓显示在"Portfolio"中
- 可以随时查看当前价值
- 结果揭晓后，自动结算

## 踩坑提醒

::: warning 坑 1：把预测市场当赌博
只看收益率，不研究事件本身，盲目下注。

**正确做法**：预测市场的价值在于信息聚合。参与前要做研究，理解事件的背景和可能的结果。
:::

::: warning 坑 2：忽视结算规则
不仔细阅读结算规则，导致对结果的理解与市场不一致。

**正确做法**：每个市场都有详细的结算规则，说明什么情况算"是"，什么情况算"否"。参与前必须仔细阅读。
:::

::: warning 坑 3：过度投入
看到高收益率就大量投入，忽视风险。

**正确做法**：预测市场是高风险活动。只用亏得起的钱参与，不要影响正常生活。
:::

::: warning 坑 4：忽视流动性
在流动性低的市场下大单，导致滑点过大。

**正确做法**：查看市场的交易量和订单簿深度。流动性低的市场，买卖价差大，不适合大额交易。
:::

## 预测市场的应用场景

### 场景一：获取信息

预测市场的价格反映了市场对事件的预期。你可以通过观察价格变化，了解市场情绪。

**示例**：
- 某项法案通过的概率从30%上升到70%，说明市场认为通过的可能性大增
- 某个加密项目上线的概率下降，可能意味着有负面消息

### 场景二：对冲风险

如果你持有某个资产，可以通过预测市场对冲风险。

**示例**：
- 你持有大量BTC，担心某个监管政策会导致价格下跌
- 你可以在预测市场买入"监管政策通过"的份额
- 如果政策通过，BTC下跌，但你在预测市场获利，部分抵消损失

### 场景三：投机

如果你对某个事件有独特的见解，可以通过预测市场获利。

**示例**：
- 你认为市场低估了某个事件发生的概率
- 你买入相应的份额，等待市场价格上涨或结果揭晓

::: warning 投机风险
投机是高风险活动。即使你的分析正确，市场也可能长时间不认可你的观点。
:::
