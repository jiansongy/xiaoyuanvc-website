## 什么时候用这一招

生息稳定币适合以下场景：

| 场景               | 为什么用生息稳定币              | 推荐产品     |
| ------------------ | ------------------------------- | ------------ |
| **长期持有稳定币** | 与其让钱躺着，不如赚点利息      | sDAI（稳健） |
| **熊市避险**       | 市场下跌时，稳定币+利息双重保护 | sDAI（稳健） |
| **追求更高收益**   | 愿意承担更高风险换取更高回报    | USDe（激进） |
| **DeFi 深度玩家**  | 理解机制，能够管理风险          | 根据策略选择 |

::: warning 不适合的场景

- **短期持有**：频繁进出会被 Gas 费吃掉收益
- **风险厌恶者**：任何生息产品都有风险，0% 收益的 USDC 可能更适合你
- **不理解机制**：如果看完这节课还是不懂，先别碰
  :::

## 30 秒理解本课

如果你对 DeFi 完全陌生，先用这个类比理解全课的核心：

> **传统稳定币** = 把钱锁在家里的保险箱（安全但不赚钱）
> **sDAI** = 把钱存进银行定期（银行拿去放贷，给你分利息，约 5%）
> **USDe** = 把钱交给对冲基金（用复杂策略赚更多，约 15%，但可能亏）

记住这个类比，后面的技术细节就容易理解了。

## 核心思路

### 传统稳定币 vs 生息稳定币

先搞清楚一个基本问题：**为什么传统稳定币没有收益？**

::: info 传统稳定币的"秘密"
当你持有 USDT 或 USDC 时，发行方（Tether、Circle）拿着你的钱去买美国国债，赚取 4-5% 的利息。但这些利息**全部归发行方所有**，你一分钱都拿不到。

换句话说：你承担了持有稳定币的风险，但收益被发行方独吞了。
:::

生息稳定币的核心理念是：**把收益还给用户**。

### 生息稳定币对比表

| 类型     | 代表      | 年化收益 | 收益来源        | 风险等级 | 适合人群       |
| -------- | --------- | -------- | --------------- | -------- | -------------- |
| 传统     | USDT/USDC | 0%       | -               | 低       | 所有人         |
| 链上生息 | sDAI      | ~5%      | 借贷协议利息    | 中       | 进阶用户       |
| 外生收益 | USDe      | ~15%     | 对冲收益+手续费 | 较高     | 了解风险的用户 |

接下来详细讲解两种主流生息稳定币的机制。

## sDAI：链上生息的稳健选择

### 什么是 sDAI？

::: info 一句话定义
**sDAI**（Savings DAI）是 Sky 协议（原 MakerDAO）推出的生息稳定币。你把 DAI 存入协议，协议把这些 DAI 借给其他用户收取利息，然后把利息分给你。
:::

### sDAI 的收益机制

```
┌─────────────────────────────────────────────────────────────┐
│                    sDAI 收益流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   你 ──存入 DAI──→ Sky 协议 ──借出 DAI──→ 借款人            │
│                        │                    │               │
│                        │                    │               │
│                        ↓                    ↓               │
│   你 ←──分配利息─── 利息池 ←──支付利息───┘               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**收益来源**：借贷协议的利息收入

这是一个很传统的商业模式，和银行存款类似：

1. 你把钱存进去
2. 协议把钱借给需要的人
3. 借款人支付利息
4. 协议把利息分给存款人（扣除一部分作为协议收入）

### sDAI 的特点

**优点**：

- ✅ **收益来源清晰**：来自真实的借贷需求，不是凭空产生
- ✅ **相对稳健**：基于超额抵押的借贷，借款人违约风险低
- ✅ **可随时提现**：没有锁定期，想取就取
- ✅ **链上透明**：所有数据可在区块链上查询

**缺点**：

- ❌ **收益率波动**：随市场借贷需求变化，牛市高、熊市低
- ❌ **收益率相对较低**：通常在 3-8% 之间，不如一些激进产品
- ❌ **需要 Gas 费**：存入和取出都需要支付以太坊网络费用

### sDAI 当前收益率

::: tip 如何查看实时收益率
访问 [Sky Finance](https://sky.money/) 或 [Spark Protocol](https://spark.fi/)，可以看到 sDAI 的实时年化收益率（APY）。

收益率会随市场变化，以实际显示为准。
:::

## USDe：高收益的激进选择

### 什么是 USDe？

::: info 一句话定义
**USDe** 是 Ethena 协议推出的合成稳定币。它不是靠美元储备支撑，而是通过持有 ETH 等资产并在衍生品市场做空对冲，实现价格稳定的同时赚取对冲收益。
:::

这个机制比较复杂，我们一步步拆解。

### USDe 的收益机制

```
┌─────────────────────────────────────────────────────────────┐
│                    USDe 收益流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   用户存入 ETH/stETH                                        │
│         │                                                   │
│         ↓                                                   │
│   协议持有 ETH ←──────────────────────────────┐            │
│         │                                      │            │
│         ↓                                      │            │
│   同时在期货市场做空 ETH ──→ 对冲价格风险      │            │
│         │                                      │            │
│         ↓                                      │            │
│   收益来源：                                   │            │
│   1. stETH 质押收益（~3-4%）                   │            │
│   2. 做空获得的资金费率（牛市时很高）          │            │
│   3. 交易手续费分成                            │            │
│         │                                      │            │
│         ↓                                      │            │
│   分配给 sUSDe 持有者（质押 USDe 的用户）      │            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 为什么 USDe 收益这么高？

关键在于**资金费率**（Funding Rate）。

::: details 什么是资金费率？
在永续合约市场，多头（看涨）和空头（看跌）需要定期互相支付费用，以保持合约价格和现货价格一致。

- **牛市时**：多头多、空头少 → 多头付钱给空头 → 做空的人赚钱
- **熊市时**：空头多、多头少 → 空头付钱给多头 → 做空的人亏钱

USDe 协议持有 ETH 现货，同时做空 ETH 期货。牛市时，做空可以赚取很高的资金费率，这就是 USDe 高收益的主要来源。
:::

**收益构成**：

1. **stETH 质押收益**：约 3-4%（稳定）
2. **资金费率收益**：牛市时可能高达 20-30%（波动大）
3. **交易手续费**：协议运营收入的一部分

### USDe 的特点

**优点**：

- ✅ **收益率高**：牛市时可能达到 15-30%
- ✅ **机制创新**：不依赖传统银行储备
- ✅ **链上透明**：持仓和对冲仓位可查

**缺点**：

- ❌ **机制复杂**：普通用户难以完全理解
- ❌ **熊市风险**：资金费率可能变负，收益大幅下降甚至亏损
- ❌ **脱锚风险**：极端行情下可能偏离 $1
- ❌ **对冲失败风险**：如果对冲仓位出问题，可能造成损失

## 生息稳定币的核心风险

::: danger 重要提醒
高收益必然伴随高风险。在投入资金之前，必须理解以下风险。
:::

### 风险 1：脱锚风险

**什么是脱锚？**

稳定币的价格偏离 $1，比如跌到 $0.95 或涨到 $1.05。

**sDAI 的脱锚风险**：

- 相对较低，因为 DAI 本身有超额抵押支撑
- 但 DAI 历史上也出现过短暂脱锚（如 2020 年 3 月）

**USDe 的脱锚风险**：

- 相对较高，因为依赖复杂的对冲机制
- 熊市时，如果大量用户同时赎回，可能造成脱锚
- 2024 年曾出现过短暂脱锚事件

### 风险 2：对冲失败风险（USDe 特有）

USDe 的稳定性依赖于对冲仓位的正常运作。如果：

- 交易所出问题（如 FTX 倒闭）
- 对冲仓位被强制平仓
- 市场极端波动导致对冲失效

都可能造成 USDe 价值损失。

### 风险 3：智能合约风险

所有 DeFi 产品都有智能合约风险：

- 代码漏洞可能被黑客利用
- 协议升级可能引入新问题
- 治理攻击可能改变协议规则

### 风险 4：收益率波动风险

- **sDAI**：收益率随借贷市场供需变化，可能从 8% 降到 2%
- **USDe**：收益率随资金费率变化，熊市可能变成负收益

### 风险评估对比

| 风险类型         | sDAI           | USDe              |
| ---------------- | -------------- | ----------------- |
| 脱锚风险         | 低             | 中-高             |
| 对冲失败         | 无             | 有                |
| 智能合约风险     | 中（协议成熟） | 中-高（协议较新） |
| 收益波动         | 中             | 高                |
| **综合风险等级** | **中**         | **较高**          |

## 实践环节：使用生息稳定币

### 练习：将稳定币存入 sDAI

::: warning 前置检查

- 已完成上一课《稳定币基础》
- 有一个支持以太坊的钱包（如 MetaMask）
- 钱包中有少量 ETH 用于支付 Gas 费
- 准备 $50 左右的 USDC 或 DAI 用于练习
  :::

**目标**：学习生息稳定币的实际操作

**时间**：约 40 分钟

### 第 1 步：准备资金

**为什么**：需要有稳定币才能存入协议

1. 确保钱包中有 $50 左右的 USDC 或 DAI
2. 确保有足够的 ETH 支付 Gas 费（建议至少 $20）

**你应该看到**：钱包余额显示 USDC/DAI 和 ETH

### 第 2 步：访问 Sky Finance

**为什么**：这是 sDAI 的官方平台

1. 打开浏览器，访问 [sky.money](https://sky.money/)
2. 点击"Connect Wallet"连接你的钱包
3. 选择 MetaMask 或你使用的钱包

**你应该看到**：钱包连接成功，页面显示你的地址

### 第 3 步：将 USDC 换成 DAI（如果需要）

**为什么**：sDAI 需要用 DAI 存入

如果你持有的是 USDC：

1. 在 Sky Finance 找到"Swap"功能
2. 选择 USDC → DAI
3. 输入金额，确认交易

**你应该看到**：交易完成后，钱包中有 DAI

### 第 4 步：存入 DAI 获得 sDAI

**为什么**：这是赚取收益的核心步骤

1. 在 Sky Finance 找到"Savings"或"sDAI"入口
2. 输入要存入的 DAI 数量
3. 点击"Deposit"或"Save"
4. 在钱包中确认交易

**你应该看到**：

- 交易确认后，钱包中出现 sDAI
- 页面显示你的存款金额和预期年化收益率

### 第 5 步：观察收益

**为什么**：理解收益是如何累积的

1. 记录当前的 sDAI 数量
2. 等待几天后再次查看
3. 对比 sDAI 数量的变化

::: tip sDAI 的收益机制
sDAI 的收益不是通过"发利息"的方式，而是通过 sDAI 对 DAI 的汇率上涨来体现。

比如：

- 今天 1 sDAI = 1.05 DAI
- 一年后 1 sDAI = 1.10 DAI
- 你的 sDAI 数量不变，但能换回更多 DAI
  :::

- [ ] 成功连接钱包到 Sky Finance
- [ ] 钱包中有 sDAI 代币
- [ ] 能看到预期年化收益率

## 踩坑提醒

::: warning 坑 1：Gas 费吃掉收益
以太坊网络的 Gas 费可能很高。如果你只存入 $50，Gas 费可能就要 $10-20，需要很长时间才能通过收益赚回来。

**应对**：存入金额尽量大一些（建议 $500 以上），选择 Gas 费较低的时段操作，或考虑使用 Layer 2 网络上的类似产品。
:::

::: warning 坑 2：频繁进出
每次存入和取出都需要支付 Gas 费。频繁操作会大幅降低实际收益。

**应对**：确定好策略再操作，不要频繁进出。长期持有才能体现生息稳定币的价值。
:::

::: warning 坑 3：只看收益率不看风险
15% 的收益率很诱人，但背后的风险可能让你亏掉本金。

**应对**：先理解收益来源，再决定是否投入。不懂的产品不要碰，只投入亏得起的钱。
:::

::: warning 坑 4：忽视智能合约风险
DeFi 协议可能被黑客攻击。历史上有多个协议被盗数亿美元。

**应对**：选择经过时间检验的成熟协议（如 Sky/MakerDAO），不要把所有资金放在一个协议，关注协议的安全审计报告。
:::

## 本课小结

::: tip 核心要点

1. **传统稳定币 vs 生息稳定币**：
   - 传统稳定币（USDT/USDC）：0% 收益，发行方独吞利息
   - 生息稳定币：把收益还给用户

2. **sDAI（链上生息）**：
   - 收益来源：借贷协议利息
   - 年化收益：约 5%
   - 风险等级：中
   - 适合人群：进阶用户，追求稳健收益

3. **USDe（外生收益）**：
   - 收益来源：对冲收益 + 资金费率 + 手续费
   - 年化收益：约 15%（波动大）
   - 风险等级：较高
   - 适合人群：了解风险的用户

4. **核心风险**：
   - 脱锚风险：价格偏离 $1
   - 对冲失败风险：USDe 特有
   - 智能合约风险：代码漏洞
   - 收益波动风险：收益率不稳定

5. **投资原则**：
   - 高收益 ≠ 无风险
   - 理解机制再投入
   - 只投入亏得起的钱
   - 新手从 sDAI 开始
     :::
