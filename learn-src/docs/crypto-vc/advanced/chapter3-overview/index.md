## 前言

如果比特币是数字黄金，那[以太坊](https://ethereum.org/)就是数字白银。中国投资者通俗地把比特币叫大饼，以太坊叫二饼。其实二者有着本质的不同，比特币是计算器（类似商贸交易的记账本），而以太坊是计算机（全球共享的公共计算平台）。

恰恰因为以太坊的出现，使得加密货币底层的区块链技术，可以提供云计算服务了。基于这种计算能力上，创业者可以创建出丰富多彩的应用（比如下节课讲的稳定币，就是一种应用，还有去中心化金融DeFi等），为此我们都得感谢创建了以太坊的[19岁少年V神](https://x.com/VitalikButerin)。

## 从“数字货币”到“可编程产权”

以太坊的出现是，因为V神发现在比特币上扩展功能很困难。原来人们给功能手机（比如诺基亚手机）开发应用很困难，直到乔布斯推出了苹果iPhone，到了智能手机时代，才有丰富多彩的应用来扩展手机功能，比如闹钟、天气预报、收音机、电视机、报刊杂志等。

所以V神的目标，是一个基于区块链的应用平台，便于创业者开发各种应用。区块链技术，给比特币和以太坊，都带来了，“去中心化的共享账本”。以太坊就是在这个共享账本上，建立了“唯一真实世界”（就像云端共享的一个[Google docs文档](https://docs.google.com/)），所有人都对“**发生了什么**”达成一致。

以太坊的创新，核心在于定义了两种账户类型：人类账户和**合约账户**。人类账户就是我们在MetaMask中，常见到的有余额和交易记录的账户，而有了合约账户，智能合约才有了“住处”（存代码的地方）和“记忆空间”（存变量的地方）。 每次交易触发合约，以太坊就会从这个账户读取旧状态、运行代码、再把新状态存回这个账户。

以太坊上运行的程序，叫智能合约，并不是跑在服务器上，而是“跑在这个共享账本上”。也就是说：代码执行结果 → 写入账本 → 所有人看到同一个执行结果。这就带来一种全新的“可信计算”范式，即以太坊通过提供“区块空间”，给参与者们，提供了可信的计算服务，这对多个（比如金融、收藏、公证等）领域，都带来了全新革命。

### 比特币和以太坊的区别：

**比特币 = 动态的“数字账本”（或电子表格）**

- **比喻**：就像一本大家共同维护的记账本，上面只记录：“张三给李四转了 1 个币”。
- 它的功能非常单一且纯粹——**记账与转账**。比特币主要记录“谁有多少钱”。

**以太坊 = 去中心化的“全球计算机”（或智能手机操作系统）**

- **比喻**：它不仅能记账，还能运行程序（App/智能合约），并且保存程序的状态！
- 如果比特币是电子计算器（只能加减乘除），以太坊就是 App Store（类似Mac、Windows这样的操作系统；类似iPhone或者是安卓这样的操作系统），任何人可以在上面开发自动执行的程序（比如自动售货机：投币就自动出货，无需人工干预）。

比特币和以太坊都使用区块链技术，来维护去中心化网络，但它们在设计、用途和功能上有所不同。

| 领域 | 比特币 | 以太坊 |
| --- | --- | --- |
| 主要用途 | 点对点数字货币 | 应用和数字经济平台 |
| 智能合约 | 不支持通用智能合约 | 核心功能 |
| 供应量 | 按协议规定的固定速率发行，最终上限为 2100 万枚 | 根据网络活动销毁，并根据质押规模发行；没有固定上限 |
| 共识机制 | 工作量证明（PoW） | 权益证明（PoS） |
| 最终性速度 | 通常以六个区块作为较强确认，平均约 60 分钟 | 达到最终性大约需要 15 分钟 |
| 能源消耗 | 高 | 低 |
| 治理 | 保守，进展缓慢 | 灵活，社区驱动 |
| 开发者生态 | 较小 | 庞大且活跃 |
| 升级 | 罕见 | 频繁且迭代 |

（对比表格来自：[Ethereum.org 的以太坊与比特币对比](https://ethereum.org/zh/ethereum-vs-bitcoin/)）

## 以太坊的基础概念

- **Ethereum，以太坊**：网络和计算平台，通常也指整个生态，生态的推动者之一是[以太坊基金会](https://ethereum.org/)。
- **Ether（ETH），以太币**：该网络的原生资产，请注意MetaMask钱包，必须有它才能执行任何交易。
- **智能合约**：部署在网络上的程序，是由以太坊虚拟机（全球计算机）来跑的程序。
- **DApp**：通过智能合约提供服务的应用，有点像在Appstore中的手机应用。

## 一笔完整的交易是如何走的

先学习六个核心概念：账户、地址、私钥、签名、交易、Gas。

1. **账户**：账户就像你在以太坊世界里的“数字钱包”，用来记录你有多少钱、做过哪些操作。
2. **地址**：地址就像你的银行卡号，别人可以用它给你转账，但不能靠它拿走你的钱。
3. **私钥**：私钥就像钱包的最高权限密码，谁掌握它，谁就能控制账户里的资产。
4. **签名**：签名就是用私钥盖上一个无法伪造的“电子印章”，证明这次操作确实是你同意的。
5. **交易**：交易就是你向以太坊发出的一条正式指令，比如转账、换币或使用一个应用。
6. **Gas**：Gas 就是付给以太坊网络处理交易的手续费，操作越复杂，通常费用越高。

以太坊上一笔完整的交易，需要经历**用户签名、广播进入内存池、验证并打包进区块、以及全网执行与确认**这四个核心步骤。整个过程，将用户的意图，转化为全球账本上的永久记录。

### 交易的创建与签名

- **填写信息**：用户在钱包中输入接收方地址、转账金额以及愿意支付的 Gas 费上限。
- **私钥签名**：钱包用用户的私钥，对这笔交易数据进行数学签名，证明这确实是该账户发出的合法指令，同时生成一笔完整的原始交易数据。

### 广播与进入内存池 (Mempool)

- **发送给节点**：钱包将签名后的交易，通过网络，发送给最近的以太坊全节点。
- **暂存等待**：节点初步检查交易格式和账户余额无误后，会将其放入一个叫作内存池的待打包区域，等待验证人来挑选。

### 共识打包与出块

- **验证人挑选**：在以太坊目前的权益证明（PoS）机制下，当前的区块提议者（验证人），从内存池中挑选多笔交易，按 Gas 费高低等策略排列。
- **构建新区块**：验证人把这些交易打包成一个新区块，运行并计算出最新的全球状态，然后广播给全网的其他验证人。

### 全网确认与状态更新

- **共识确认**：其他节点收到新区块后，会独立重新执行区块里的每一笔交易，验证结果是否正确。
- **写入账本**：一旦达成共识，区块被正式接到以太坊主链上，用户的账户余额改变，交易彻底完成且无法篡改。你可以通过像 Etherscan 这样的区块浏览器，实时查到这笔交易的最终结果。

## 以太坊基金会的CROPS使命

2026年年初，加密货币行业发生了大讨论：以太坊是追求“最多被采用的全球结算层”，还是“最坚韧的数字庇护所”？Vitalik 明确选择了后者作为优先级，也就是我们常说的“去中心化、无需许可、无需信任、不可篡改”。

由此，以太坊主动放弃追求增长和采用率、成为全球金融基础设施的目标，而要为**最黑暗的危机时刻，长远提供“去中心化”的CROPS保护（像庇护所一样的韧性或硬度）**，甚至比比特币更加去中心化。

**CROPS**  是以太坊基金会在 **2026年3月13日**正式发布《使命宣言》时，明确提出的四项基本原则：

1. **CR — Censorship Resistance：抗审查性**
2. **O — Open Source and Free：开源且自由**
3. **P — Privacy：隐私**
4. **S — Security：安全**

| 原则 | 官方含义 | 解决痛点 | 通俗说法 | 判断标准 |
| --- | --- | --- | --- | --- |
| 抗审查性 | 参与者不能选择性阻止有效使用，系统不能依赖中心化中介或终止开关 | 被平台冻结账户 | 有没有一个人能按下暂停键？ | 谁能阻止我 |
| 开源且自由 | 没有隐藏规则和黑箱；代码可以审计、复制、修改和分叉 | 被平台秘密修改推荐或交易规则 | 规则能不能看，系统能不能另起炉灶？ | 谁能修改、隐藏或垄断规则 |
| 隐私（待改进） | 用户数据不应被过度暴露，用户能够选择向谁披露什么 | 所有行为被用于建立个人画像 | 用户能不能决定别人看到什么？ | 谁能看到我的信息 |
| 安全 | 系统必须准确完成它承诺的事情，不多做，也不少做 | 合约漏洞、钓鱼签名和管理员后门 | 它会不会被偷、被改或做出意外行为？ | 谁能偷走、篡改或误导我 |

CROPS不是以太坊已经完美实现的四项功能，而是以太坊任何时候都不能放弃的四个方向。目前以太坊在“隐私”方面还有缺陷，正在改进之中。部署在以太坊上的DAPP，并不一定是符合CROPS四项原则的，因为很多应用留有管理员的后门，所以还是可以冻结你的账号或者把你从平台上踢掉。

CROPS也是判断一个数字系统，是否**真正属于用户**的四把尺子：**不可封、可验证、少暴露、不作恶**。

## 现代以太坊既有一层也有二层网络

以太坊一层网络是“最终记账和裁判的总账本”，二层网络是“先替大家快速办业务，再把压缩后的账单和证据交回一层确认”。以一个大学的财务系统来举例，上万个同学都从学校财务部，收到了一个校园卡，他们在食堂中买餐的交易，直接用卡在食堂的收银机（二层）上就处理了，而不必每次都到财务部（一层）进行结算。

具体到以太坊的场景，看下图。Base和Arbitrum是目前最流行的两个二层网络，其他还有很多的二层网络。

| 阶段 | 发生什么 |
| --- | --- |
| 用户交易 | 用户发出约 1000 笔交易 |
| 二层执行 | Base、Arbitrum 等二层网络快速执行、排序和打包 |
| 批量提交 | 二层把一批交易及必要的数据或证据提交给一层 |
| 一层结算 | Ethereum 保存数据，负责结算和最终裁决 |

### 一笔二层交易到底怎么走

第一步：用户发交易：学生在 Base 上用 USDC 买一件商品，钱包签名后把交易发给 Base。

第二步：二层快速执行：Base 的排序器将交易排序、执行，用户很快便能看到结果。

第三步：批量压缩：Base 将许多人的交易打成一个“大包裹”，而不是逐笔，发给以太坊。

第四步：提交给以太坊：二层把必要的交易数据和状态结果提交到以太坊。

第五步：以太坊最终结算：以太坊保存必要数据，并作为争议处理和最终结算层。

### 二层网络的总结

以太坊一层网络是安全、数据和最终结算层。二层网络是快速、低成本的交易执行层。最流行的两个二层网络例子是：Base代表大众应用与入口，Arbitrum代表DeFi和链上金融。
