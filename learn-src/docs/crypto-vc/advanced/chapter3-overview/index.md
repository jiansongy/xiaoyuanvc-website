# 第三章：金融篇

## 本章导读

2025 年随着美国稳定币 GENIUS 法案通过，迎来了加密货币的"ChatGPT 时刻"。加密货币的技术栈明显优于传统金融摇摇欲坠的 IT 基础设施，区块链正在成为新一代的金融基础设施。类似于互联网对媒体业的重构，全球正在上演加密货币对金融业的重构。

加密货币中已被验证的大赛道有两个——**"金融和赌博"**，也有人称为"大教堂和大赌场"。在金融之下有很多细分赛道，它们的名称中都带一个 **Fi** 后缀，即 Finance（金融）的含义。比如 SocialFi、GameFi、InfoFi、AgenticFi、PredictFi 等等。我们常接触的加密应用有三个（支付、融资和交易），也都属于金融大赛道。

本章将从稳定币——加密货币的"血液"——讲起，带你了解加密金融的核心产品和运作逻辑。

## 关键术语速查

本章涉及大量金融概念，先用一句话扫盲：

| 术语         | 一句话定义                                                           |
| ------------ | -------------------------------------------------------------------- |
| **稳定币**   | 价格锚定美元的加密货币（1 USDT ≈ 1 美元），是加密世界的"现金"        |
| **DeFi**     | 去中心化金融，用代码代替银行来完成借贷、交易、保险等金融服务         |
| **智能合约** | 写在区块链上的自动执行程序，条件满足就自动执行，不需要人来操作       |
| **AMM**      | 自动做市商，用数学公式代替传统交易所的买卖撮合，让任何人随时可以交易 |
| **ETF**      | 交易所交易基金，让传统投资者通过股票账户买比特币，不需要懂加密货币   |
| **永续合约** | 没有到期日的期货合约，可以加杠杆做多（看涨）或做空（看跌）           |
| **Gas 费**   | 在区块链上执行操作需要支付的手续费，类似于银行的转账手续费           |

## 核心问题

1. **稳定币为什么是加密货币的"杀手级应用"？** 它如何改变跨境支付和全球金融？
2. **DeFi 和传统金融有什么本质区别？** "代码即法律"意味着什么？
3. **什么是 AMM 自动做市商？** 它如何颠覆传统交易所的订单簿模式？
4. **比特币 ETF 为什么意义重大？** 它对机构入场和市场格局有何影响？
5. **永续合约是什么？** 杠杆交易的风险和机会在哪里？
