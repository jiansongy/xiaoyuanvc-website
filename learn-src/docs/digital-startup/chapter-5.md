# 第五章：融资致胜法则

第五课谈“从零到英雄-玩创投”的第三个阶段“投”了。

虽然你作为创业新手，尚未到“投”的阶段，但通过本课提前认知，也会有帮助。

<text color="red" bgcolor="light-yellow">创业要</text><text color="red" bgcolor="light-yellow">**多行动**</text><text color="red" bgcolor="light-yellow">，投资要</text><text color="red" bgcolor="light-yellow">**少决策**</text>**。**我也是很多年以后，经过多次被打击，才悟到原来从创到投需要切换风格。

创业者是开创业项目这辆车的司机，而投资者则是坐在副驾驶位子上。

**提问**：「你们觉得创业成功最重要的事是什么？是搞融资还是做业务？」

<quote-container>

融资只是给车加油。油不是目的，开到目的地才是。

很多创业者花了 80% 的时间找油，忘了开车。
</quote-container>

**本课目标**：学完今天这节课，你能在 30 秒内把自己的项目讲清楚，并且知道什么时候该去找投资人。

# 风险投资是什么

风险投资是给创业公司提供股权资金并期待以此盈利的财务公司。

如果你想深入了解这个风险投资行业，推荐阅读美国硅谷《[风险投资史](https://book.douban.com/subject/36171394/)》和《[中国风险投资史](https://book.douban.com/subject/37852019/)》

## 风险投资是干什么的

风险投资的本质是：用分散的小赌注，押注人，等时间，而非靠流程和运气。

风险投资是一种赢家通吃的生意，所有的回报都来自最头部的几个项目，这就是幂律（Power Law）。

风险投资需要不断地寻找与众不同的人，比如 Meta 扎克伯格、以太坊 V 神（你猜猜他创业时几岁）等

风险投资用小钱押很多赛道——大多数项目会死，少数项目回报极高。

他们不找「能赚 3 倍的项目」，只找「万一成了能赚 100 倍的项目」

## 融资的三个早期阶段

| 阶段 | 状态 | 小店类比 |
| --- | --- | --- |
| **种子轮 / 天使轮** | 有想法，在验证 | 借钱进货，看有没有人买 |
| **A 轮** | 有用户，要扩大 | 店开起来了，要多开几家 |
| **B 轮以后** | 先不管 | 那是几年后的事 |

## 投资股权而非债权

给股权 = 分公司的一块利益给他。公司赚了他也赚，公司倒了他也没了。

给债权 = 公司必须要还的钱。现实中也有“名股实债”的情况出现。

# 你应该去融资吗？

你觉得拿到融资是创业成功的标志吗？

很多人创业一缺钱，就想着要去找融资。但是融资背后有很多陷阱，需要你“与狼共舞”。

## 真相 1：融资是有代价的

拿了风险投资的钱，你就踩上了跑步机——必须每年高速增长，不能慢下来，否则投资人会换掉你。

**案例：ofo 小黄车（已经倒闭的共享单车公司）**

<quote-container>

2016 年融了大量资本，被迫烧钱补贴、疯狂扩张、全国铺车。

最终资金链断裂，几千万用户的押金无法退还。

不是产品不好，是资本逼着它超速跑，跑断了腿。
</quote-container>

## 真相 2：先找用户，再找投资人

**案例：Gumroad（类似国内的小鹅通）**

<quote-container>

《小而美》的作者 Sahil Lavingia 做了一个帮创作者卖东西的平台。

硅谷 VC 追着他投钱，他拒绝了，选择小而美地盈利运营。

平台每年给创作者结算上亿美元，他至今自己做所有决定。
</quote-container>

**结论**：

找到 10 个愿意付钱的用户 > 找到 1 个投资人

### 事实上

天使投资的本质是抵押未来的贷款

投资者虽然占股小，但权利（少数股东）高于创业者

对创业者，出钱的客户远比投资者重要

所以在找到10个付费客户之前，先不要去找投资

创业者要用出人意料少的资源，做成出人意料多的事情 

创业者也是有资本的，有两大资本：愿景资本和汗水资本

# 天使投资的 3 条真相

天使投资是极早期风险投资，其成功概率很低。

《[超级天使投资](https://book.douban.com/subject/26378772/)》一书说：“必须投资**20个项目**，才有机会成功1个项目”。

## 真相 1：大多数项目会失败，投资人知道这一点

他们不是找「不会失败的项目」，而是找「万一成了能回报 100 倍的项目」。

你被拒，不代表你的项目不好。

## 真相 2：早期最重要的是团队，不是商业模式

<quote-container>

Facebook 拿天使投资时还没有商业模式。

Peter Thiel 投的是扎克伯格这个人，不是商业计划书。
</quote-container>

## 真相 3：最终表现好的，往往一开始看起来很普通

<quote-container>

马云 1999 年去硅谷路演 Alibaba，被所有 VC 拒绝了。

现在被引为经典的公司，当年几乎都曾被否定过。
</quote-container>

# 融资路演入门

路演的本质是讲好故事，感召各方投入到这个项目中，和你一起干。

**激情**是讲好故事的灵魂，它可以让人们为了实现梦想而奋斗。

**电梯演讲**：来自麦肯锡的30秒电梯比喻，要求业务人员能在30秒时间内向客户介绍清楚方案，

融资讲故事的目的，是给听众带来梦幻般的感觉，引领听众去那个流淌着牛奶和蜂蜜的地方。

## 讲述逻辑

世界正发生一个重大且相关的变化

该变化将带来成功者和失败者

激发听众对 “流奶与蜜之地”的憧憬

我们的方案有能力带听众跋涉到该地

并提供证据，证明这个美梦可以成真

所以呼吁听众们行动，出人出钱等

**听众脑力有限，因此控制在1分钟之内，越短越好，这就是“电梯演讲”**

# 怎么讲好你的故事

## 融资叙事的技能

以 Claude code 为代表的编程智能体，不仅可以帮你开发网站和软件、做营销增长，还可以帮你做融资叙事，因为代码几乎是万能的。只要是电脑上干的事，Claude code 等都能干，前提是安装上**适当的技能**。

因此推荐这个能生成融资叙事的技能：https://github.com/guia-matthieu/clawfu-skills/blob/main/skills/startup/fundraising-narrative/SKILL.md

这套教你如何讲好融资故事的方法论，来源于 Reid Hoffman（LinkedIn 创始人/Greylock）、红杉资本和 YC 合伙人等的实战框架。它的核心信条是：投资人投的不是项目本身，而是他们相信的**关于未来的叙事**。

该技能提供一套完整的叙事弧线——从发现洞见、构建"为什么是现在"的紧迫感，到预判投资人的质疑并化解——帮助创始人在见投资人之前，就把故事打磨清楚。

这个技能解决的是，早期创始人最普遍的一个卡点：想法说不清楚。

叙事能力不只是融资时才用到。招募联合创始人、说服导师给资源、写第一版产品文案、在比赛路演中脱颖而出——这些众多的场景，都需要同一种能力：**让对方相信**<text underline="true">**你看到了**</text>**别人还没看到的机会**。

## 镜子游戏（标准 4 步）

1. 演讲者做 30 秒电梯演讲 → 倾听者「镜像复述」听到的内容
2. 演讲者评估复述准确度 → 改进演讲
3. 用修改后版本重复，倾听者可做笔记并分享 30 秒想法
4. 再重复一轮，双方各记笔记，互相分享 1 分钟反馈
5. 最后演讲者向全班做最终版演讲 → 角色互换

## 尖锐提问的例子

在融资中，Pitch（意为投球、投掷）指创业者在有限时间内（通常为数分钟到十分钟），以简短、精炼、充满说服力的方式向投资者介绍商业计划、产品、服务、业务数据和团队优势，目的是吸引投资者兴趣、获取下一次会面机会或直接争取资金。

「**被打断的 pitch**」：倾听者在 30 秒时举手问一个尖锐问题，演讲者必须接住后，再继续讲完。

常用尖锐问题参考：

- 「你们现在有多少真实付费用户？」
- 「这件事微信 / 抖音为什么不直接做？」
- 「你们团队有没有人做过类似的事？」

# 3C 数字资产

我把数字资产分为三类：

1. **Content：内容资产**，比如你发在微信中的图文、抖音中的短视频、B 站小红书中的内容等 
1. **Code：软件代码，**比如微信、抖音、小红书等诸多应用了人工智能和区块链等的 App 或者软件
1. **Crypto：加密货币，**是软件代码高级形态（不仅源代码开源、而且运行状态也开源），比如比特币等，加密货币行业往往自称是“Web3”，突出自身“可读、可写、可拥有”的特色。

“软件型”3C数字资产，是可以存在小U盘中带走的数字文件，而非传统的“硬件型”3C数码，注意区分。

当今最热门的数字资产，无外乎是人工智能与加密货币。因此我们数创班在学习人工智能创业，而加密创投营在学习加密货币领域的创业与投资。

# 本课内容总结

1. 融资只是财务工具，不是目标——先找用户，再找投资人
2. 融资 PPT 的第一页，要放最强证据，而不是放市场规模
3. 被投资人拒绝很正常，准备好讲 100 次，才能找到融资
1. 3C 数字资产是指：内容 Content、软件 Code 和加密货币 Crypto
