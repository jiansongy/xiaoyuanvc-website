# 数字创业教程

怎样用数字工具做生意？一个想法要经过哪些检验，才值得做成产品？这套免费教程来自校园 VC 第十一期数创班，由殷建松主讲。原课程为六周，用 AI 做一次真实创业探索，重点是找到真实用户、做出 AI 原型、用证据复盘。可以从头读，也可以从眼下遇到的问题读起。

1. [创业认知](./chapter-1)　什么是数字创业？一个人怎样组织 AI 智能体，把一次劳动变成可以反复使用的内容或软件？
2. [AI 认知](./chapter-2)　怎样用小实验验证想法？AI 可以帮你收集哪些资料、处理哪些业务？
3. [产品实务](./chapter-3)　怎样问出真实需求，用最简的办法让用户试一次？
4. [营销实务](./chapter-4)　谁最需要你的产品？怎样让客户知道你、找到你、愿意付钱？
5. [资本实务](./chapter-5)　什么时候值得融资？怎样用证据把自己的生意讲清楚？
