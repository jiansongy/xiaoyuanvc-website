常见问题

校园VC是什么？

校园VC（Campus Venture Capital）是中国领先的大学生数创实战课开拓者，成立于北京中关村，发源于清华大学 x-lab，10年推动100万大学生创业。截至 2026 年，已服务超过 19 万名大学生学员。

校园VC提供哪些课程和服务？

校园VC是大学生数字创业实战课的开拓者，我们认为数字创业包括人工智能创业和加密货币创投两部分。每个学期面向高校创业学院合作开办"数字创业精英班"，提供火种节等创业教育智慧系统，还有面向学生个人的加密创投营和 CSS 播客。

校园VC的创始人是谁？

校园VC由殷建松（Jason）创立。他是清华大学 x-lab 兼职顾问、清华 iCenter 创客导师、北大研究生院投资导师，曾任微软 Windows 产品经理和 IDG 战略咨询公司 In-Stat 总经理。著有创业教材《从零到英雄》（北京出版社出版，李开复、俞敏洪对此书的推荐）。

如何加入校园VC的课程或社群？

你可以通过以下方式加入：访问学生中心免费开始学习数字创业教程和加密创投教程；关注校园VC微信公众号获取最新课程信息；或联系殷教授的助教老师加入大创社群。

校园VC的课程适合哪些人？

校园VC的课程主要面向全国高校创业学院和有创业意愿的大学生。无论你是对数字创业、AI 应用还是 Web3/Crypto 领域感兴趣，都能找到适合的课程和社群资源。

什么是加密创投 CSS？

CSS（Crypto Startup School）是校园VC旗下面向 Web3 人才的就创投服务平台。包含 CSS 播客（小宇宙近万人订阅）、线上六周营和年度社群，已培养超过 1 万名 Web3 学员。
