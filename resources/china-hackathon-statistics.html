如何准备第一场黑客松？

新手三步准备法：

  1. 补产品思维 — 学习如何发现真实问题、定义需求。推荐：校园VC数字创业教程
  2. 掌握AI工具 — Claude Code / Cursor / 豆包 可以快速生成原型，即使不会编程也能做出Demo
  3. 组队或找队友 — 提前在赛事组队群认识队友，或现场组队（带着2-3个初步想法去）

教师如何在课堂组织黑客松？

传统黑客松需要大量准备（场地、赞助、志愿者、评委），对高校教师来说门槛较高。校园VC的 火种节 把黑客松式协作压缩成3小时课堂活动：

  • 用投票选创意，保证质量下限
  • 队长招聘组队，模拟真实市场
  • 软件引导9个里程碑，流程不失控
  • 鼓励"疯狂而愚蠢"的创意，激发玩的精神

历史上"复活恐龙"落地成研学旅行、"光合作用"引导学生查科研论文——课堂版黑客松同样能让学生做出令人着迷的项目。
